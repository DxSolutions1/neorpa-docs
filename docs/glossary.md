# 용어집

| 용어 | 설명 |
|---|---|
| **프로젝트** | 워크플로와 설정을 묶은 폴더. `project.json`(이름·설명·시작 워크플로)과 `.xaml` 파일들이 들어 있으며, 디자이너는 한 번에 하나의 프로젝트를 연다. |
| **`project.json`** | 프로젝트 폴더의 정보 파일. 시작 화면의 "로컬 프로젝트 열기"에서 선택하면 그 프로젝트가 열린다. |
| **워크플로** | 자동화 동작을 순서·조건·반복으로 엮은 단위. WF `.xaml` 파일로 저장. 새 프로젝트의 시작 워크플로는 `Main.xaml`. |
| **액티비티** | 워크플로를 구성하는 최소 동작 블록(클릭, 입력, Excel 읽기 등). 도구상자에서 카테고리별로 제공. |
| **셀렉터** | 화면 요소를 식별하는 XML 태그 목록. 첫 줄이 루트(창/탭), 이후 자손 체인. |
| **부분 셀렉터** | 창/탭 정보(루트)가 빠진 셀렉터. Attach 스코프 안에서만 동작하며, 스코프가 루트를 채워 준다. |
| **스코프** | Attach 스코프. 특정 창/탭을 대상으로 고정하고 그 안에서 자식 액티비티를 실행. |
| **요소 편집기** | 셀렉터를 확인·수정하는 창. 검증(Validate)으로 일치 요소 수를, 하이라이트로 화면 위치를 확인한다. |
| **유사 일치** | `클릭 V2`가 셀렉터와 정확히 일치하는 요소가 없을 때 이름 등이 비슷한 요소를 점수로 찾는 방식. 임계값(기본 82)으로 느슨함을 조절. |
| **채널** | 셀렉터가 속한 자동화 경로 — 로컬 UIA / 웹(크롬 확장) / RDP(원격 데스크톱). |
| **UIA / MSAA** | Windows 접근성 API. 데스크톱 UI 요소 탐색에 사용. |
| **DVC** | RDP Dynamic Virtual Channel. 원격 데스크톱 세션 위에 여는 사용자 정의 데이터 채널. |
| **Remote Runtime** | 원격 머신에서 도는 NeoRPA 에이전트(`NeoRPA.RemoteRuntime.exe`, 트레이 아이콘). 원격 세션 안에서 셀렉터 해석·입력 수행. |
| **네이티브 메시징 호스트** | 크롬 확장과 NeoRPA를 잇는 중계 프로세스(`NativeMessageNeoRPA.exe`). |
| **로그 수준** | 실행 로그 한 줄의 중요도: Trace / Info / Warning / Error / Fatal. |
| **브레이크포인트** | 디버그 실행이 잠시 멈추는 지점. 디버깅 패널에서 F5(계속)·F6·F11(단계 실행)·F7(재시도)·F8(일시중지)로 진행. |
