# 시작하기

이 문서는 NeoRPA를 처음 사용하는 분을 위해 **설치부터 첫 워크플로 실행까지**를 순서대로 안내합니다.

!!! note "준비물"
    - Windows 10/11 PC
    - 발급받은 **라이선스 코드**
    - 브라우저 자동화를 사용할 경우 Chrome 또는 Edge

## 1. 설치

NeoRPA를 설치하는 방법은 두 가지입니다. 대부분의 사용자는 **설치 프로그램(MSI)** 방식을 사용합니다.

=== "설치 프로그램(MSI)으로 설치"

    1. 배포받은 설치 프로그램 `NeoRPA-v2.1.0.0.msi`(버전 번호는 배포판에 따라 다릅니다)를 실행합니다.
    2. 안내에 따라 설치를 완료합니다.
    3. 바탕화면에 생성된 **NeoRPA** 바로가기 또는 시작 메뉴의 프로그램 목록에서 NeoRPA를 확인합니다.

=== "소스에서 직접 빌드(개발자)"

    소스 코드를 직접 빌드해 실행할 수도 있습니다. 자세한 절차는 개발자 문서(RPA 관리자 전용 포털)의 **빌드 · 테스트**를 참고하세요.

!!! info "프로그램 이름에 대해"
    설치 프로그램과 바로가기 이름은 **NeoRPA**이고, 실제 실행 파일 이름은 `Rehosted WF Designer.exe`입니다. 작업 관리자나 명령줄에서는 실행 파일 이름으로 보입니다.

## 2. 최초 1회 로컬 파일 배포

NeoRPA는 브라우저 자동화·원격 데스크톱 연동 등 일부 기능을 위해 로컬 파일 배포 단계를 **최초 1회** 실행해야 합니다.

1. 설치 폴더의 `Resources\LocalFiles\` 안에 있는 **`CopyLocalFiles.bat`** 파일을 실행합니다.
2. 실행이 끝나면 `C:\NeoRPA` 폴더가 생성되고 필요한 파일이 복사됩니다.
3. 중간에 등록 여부를 묻는 창이 나오면 **예**를 선택합니다.

!!! tip
    이 단계는 설치 후 한 번만 수행하면 됩니다. 프로그램을 재설치하거나 업데이트했을 때 다시 실행하세요.

## 3. 첫 실행과 라이선스 코드 입력

1. **NeoRPA**를 실행합니다. 관리자 권한을 요청하는 창이 나오면 허용합니다(데스크톱 자동화를 위해 관리자 권한으로 동작합니다).
2. 처음 실행하면 라이선스 입력 창이 나타납니다.
3. **발급받은 라이선스 코드를 입력**하고 확인합니다.

!!! note
    라이선스 코드는 조직의 담당자 또는 공급처를 통해 발급받습니다. 코드가 없거나 만료된 경우 담당자에게 문의하세요.

라이선스 확인이 끝나면 **시작 화면**이 열립니다.

## 4. 시작 화면과 프로젝트 { #start-screen }

NeoRPA는 자동화를 **프로젝트** 단위로 관리합니다. 프로젝트는 하나의 폴더이며, 그 안에 프로젝트 정보 파일(`project.json`)과 워크플로 파일(`.xaml`)들이 들어 있습니다. 시작 화면에는 세 가지 선택이 있습니다.

| 선택 | 동작 |
| --- | --- |
| **로컬 프로젝트 열기** | `project.json` 또는 워크플로(`.xaml`) 파일을 선택해 해당 프로젝트를 엽니다. |
| **최근 항목 열기** | 최근에 연 프로젝트 목록에서 한 번의 클릭으로 다시 엽니다. |
| **새 프로젝트 → 프로세스** | 이름(필수)·설명·위치(필수)를 입력해 빈 프로젝트 폴더를 만들고 바로 엽니다. |

!!! tip
    처음이라면 **새 프로젝트 → 프로세스**를 선택하세요. 지정한 위치 아래에 프로젝트 이름의 폴더가 만들어지고, 기본 워크플로 `Main.xaml`이 열립니다.

시작 화면을 닫으면 프로그램이 종료됩니다. 디자이너는 항상 하나의 프로젝트를 연 상태로 동작합니다.

## 5. 디자이너 화면 둘러보기 { #designer }

프로젝트를 열면 디자이너 화면이 나타납니다.

- **상단 리본**: `홈`(시작 화면으로 돌아가 다른 프로젝트 열기), `프로젝트 설정`(이름·설명 변경), `신규`(프로젝트 생성 / 시퀀스 / 플로우 차트 / 스테이트 머신), `저장`, `다른 이름으로 저장`, `실행`, `디버깅`, `중단`, `스크래핑`, 브라우저(`크롬 열기`, `엣지 열기`, 확장 프로그램 설치), `라이센스`.
- **가운데 캔버스**: 워크플로를 조립하는 작업 영역. 여러 워크플로를 탭으로 열어 둘 수 있습니다.
- **왼쪽 패널**: 하단 바의 `프로젝트`(프로젝트 폴더 트리) 또는 `액티비티`(도구상자)를 눌러 전환합니다. 도구상자 상단에는 액티비티 검색 상자가 있습니다.
- **오른쪽 속성 패널**: 캔버스에서 선택한 액티비티의 속성을 편집합니다.
- **하단 바**: `출력`(실행 로그) · `프로젝트` · `액티비티` · `디버깅` 패널을 켜고 끕니다.

### 프로젝트 패널

`프로젝트` 패널은 현재 프로젝트 폴더의 파일·폴더 트리를 보여 줍니다.

- 워크플로(`.xaml`)를 **더블클릭**하면 탭으로 열립니다(이미 열려 있으면 그 탭으로 이동).
- 마우스 오른쪽 버튼 메뉴: **새 폴더**, **새 워크플로우**, **열기**, **이름 바꾸기 (F2)**, **삭제 (Del)**, **탐색기에서 열기**, **새로 고침**.
- 파일을 드래그해 다른 폴더로 옮길 수 있습니다.

!!! warning
    프로젝트 폴더 안의 파일은 열려 있는 탭과 항상 함께 관리됩니다. 파일을 옮기거나 이름을 바꿀 때는 가능하면 탐색기 대신 프로젝트 패널을 사용하세요.

## 6. 브라우저 확장 프로그램 설치 (선택) { #browser-extension }

웹 페이지 자동화(Chrome/Edge 액티비티)를 사용하려면 전용 브라우저 확장 프로그램을 설치해야 합니다. 사용하지 않는다면 이 단계는 건너뛰어도 됩니다.

1. 리본의 **크롬** 또는 **엣지** 그룹에서 `확장 프로그램 설치`를 누르거나, 설치 폴더의 `Resources\Batch\`에서 사용할 브라우저에 맞는 바로가기 생성 스크립트를 실행합니다.
    - Chrome: `create_chrome_shortcut.bat`
    - Edge: `create_edge_shortcut.bat`
2. 바탕화면에 생성된 전용 브라우저 바로가기(또는 리본의 `크롬 열기` / `엣지 열기`)로 브라우저를 실행합니다.
3. 브라우저의 **확장 프로그램** 관리 화면에서 NeoRPA 확장 프로그램을 설치하고, 화면의 안내에 따라 등록을 완료합니다.
4. 확장 프로그램 설치 후 브라우저를 다시 시작합니다.

!!! warning "연결이 안 될 때"
    확장 프로그램을 설치했는데도 "연결되지 않음(Disconnected)" 같은 메시지가 보이면, 브라우저를 완전히 종료했다가 전용 바로가기로 다시 실행해 보세요. 그래도 해결되지 않으면 [문제 해결](troubleshooting.md#browser-extension)을 참고하세요.

## 7. 첫 워크플로 만들기

이제 간단한 워크플로를 만들어 실행해 봅니다.

1. **워크플로 열기**: 새 프로젝트를 만들었다면 `Main.xaml`이 이미 열려 있습니다. 워크플로를 추가하려면 프로젝트 패널에서 **새 워크플로우**를 선택합니다.
2. **액티비티 추가**: 하단 바의 `액티비티`를 눌러 도구상자를 열고, 원하는 액티비티(예: **System** 카테고리의 `로그 메시지 출력`)를 캔버스로 끌어다 놓습니다. 더블클릭해도 선택한 위치에 추가됩니다.
3. **속성 설정**: 캔버스에서 액티비티를 선택하면 오른쪽 속성 패널에서 값을 입력할 수 있습니다.
4. **저장**: 리본의 `저장`을 누릅니다. 워크플로는 프로젝트 폴더 안에 `.xaml` 파일로 저장됩니다.
5. **실행**: 리본의 `실행`을 누릅니다. 진행 상황과 결과는 하단 `출력` 패널의 실행 로그에 표시됩니다.

!!! tip "다음 단계"
    - 워크플로·액티비티·셀렉터가 무엇인지 먼저 이해하려면 [기본 개념](concepts.md)을 읽어보세요.
    - 카테고리별 액티비티 사용법은 [액티비티 사용법](activities/index.md)에 정리되어 있습니다.
    - 원격 데스크톱(mstsc) 안의 화면을 자동화하려면 [원격 데스크톱 자동화](remote-desktop.md)를 참고하세요.

## 8. 명령줄로 열기·실행 (고급) { #cli }

외부 도구나 스케줄러에서 NeoRPA를 호출할 때는 실행 파일에 명령줄 인수를 줄 수 있습니다. 실행 파일은 설치 폴더의 `Rehosted WF Designer.exe`입니다.

```text
"Rehosted WF Designer.exe"
    → 일반 실행(시작 화면)

"Rehosted WF Designer.exe" open --project=<프로젝트 폴더|project.json|워크플로.xaml> [--file=<먼저 열 워크플로.xaml>]
    → 시작 화면을 건너뛰고 지정한 프로젝트를 디자이너에서 바로 엽니다.

"Rehosted WF Designer.exe" execute --file=<워크플로.xaml> [--elevate]
    → 디자이너 화면 없이 워크플로를 실행하고, 실행 결과를 종료 코드로 돌려줍니다.
      --elevate 를 주면 관리자 권한으로 다시 시작해 실행합니다.
```

!!! note
    `open`은 다른 프로그램(예: 자동 변환 도구의 미리보기)이 변환 결과를 곧바로 열어 주기 위한 연동용 동사입니다. 일반 사용에서는 시작 화면을 이용하세요.
