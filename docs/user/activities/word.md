# Word (텍스트 읽기 · 바꾸기)

Word 문서(.docx)의 글을 읽고, 글을 찾아 바꿉니다. 서식 문서의 `{{고객명}}` 같은 자리를 채워 견적서·안내문을 찍어 내는 데 씁니다. 파일을 직접 다루므로 **Word 가 설치되어 있지 않아도** 되고 Word 창이 뜨지 않습니다. UiPath 의 Read Text · Replace Text(Word)에 해당합니다.

> 이 카테고리에는 2개의 액티비티가 있습니다. 각 액티비티의 **속성** 표는 소스에서 자동 추출되며(상속 포함), 표시명·설명은 리소스/설명 데이터에서 해석됩니다.

!!! note "제공 버전"
    Word 카테고리는 NeoRPA 2.2.4 다음 버전부터 제공됩니다. 툴박스에 **Word** 가 보이지 않으면 도움말 탭 → **버전 관리** 에서 새 버전을 확인하세요.

!!! warning "다루는 파일"
    - **.docx**(.docm·.dotx 포함)만 다룹니다. 예전 형식(**.doc**)과 **암호가 걸린 문서**는 Word 에서 암호 없이 .docx 로 저장한 뒤 쓰세요.
    - 문서를 PDF 로 저장하는 기능은 아직 없습니다.

## Word 텍스트 읽기  <small>`ReadWordText`</small>

Word 문서(.docx)의 글을 읽어 텍스트로 돌려줍니다. 문단마다 한 줄, 표는 행마다 한 줄(칸은 탭으로 구분)입니다. UiPath Read Text(Word)에 해당합니다.

**속성**

| 속성 | 방향 | 타입 | 설명 |
|------|------|------|------|
| 파일 경로 <small>`FilePath`</small> | 입력 | `string` | 읽을 Word 문서(.docx). 상대 경로는 프로젝트 폴더 기준입니다. 카드의 `…` 버튼으로 고를 수 있습니다. Word 에서 열어 둔 문서도 읽습니다. |
| 머리글·바닥글 포함 <small>`IncludeHeadersFooters`</small> | 설정 | `bool` | 머리글·바닥글과 각주·미주의 글도 함께 읽을지 여부(기본 false). 켜면 머리글 → 본문 → 각주·미주 → 바닥글 순서로 나옵니다. |
| 결과 <small>`Result`</small> | 출력 | `string` | 문서의 글(출력). 오류 무시를 켠 채 실패하면 빈 텍스트입니다. |
| 오류 무시 <small>`ContinueOnError`</small> | 입력 | `bool` | 이 액티비티에서 오류가 발생해도 워크플로를 멈추지 않고 계속 진행할지 여부(true/false). |

#### 읽는 모양 { #word-read-shape }

| 문서의 것 | 읽은 글 |
|---|---|
| 문단 | 한 줄(빈 문단은 빈 줄) |
| 표 | 행마다 한 줄, 칸은 탭으로 구분(칸 안의 여러 줄은 빈칸으로 이어짐) — `텍스트 나누기`로 칸을 가를 수 있습니다 |
| 글 상자 | 그 글 상자가 놓인 문단 바로 뒤 |
| 변경 내용 추적으로 지운 글 | 읽지 않습니다(최종본 기준) |
| 그림·도형 안의 글, 차트 | 읽지 않습니다 |

## Word 텍스트 바꾸기  <small>`ReplaceWordText`</small>

Word 문서(.docx)에서 텍스트를 찾아 **모두** 바꿉니다. 본문·표·글 상자·머리글·바닥글·각주에서 찾습니다. 서식 문서의 자리 표시(`{{고객명}}`)를 채워 새 문서로 저장하는 데 씁니다. UiPath Replace Text(Word)에 해당합니다.

**속성**

| 속성 | 방향 | 타입 | 설명 |
|------|------|------|------|
| 파일 경로 <small>`FilePath`</small> | 입력 | `string` | 고칠 Word 문서(.docx) — 서식 문서. 상대 경로는 프로젝트 폴더 기준입니다. |
| 찾을 텍스트 <small>`SearchText`</small> | 입력 | `string` | 찾을 텍스트(글자 그대로). 화면에 이어져 보이는 글이면, 파일 안에서 서식이 여러 조각으로 나뉘어 있어도 찾습니다. 탭·줄바꿈·다른 문단에 걸친 글은 찾지 않습니다. |
| 바꿀 텍스트 <small>`Replacement`</small> | 입력 | `string` | 바꿀 텍스트. 비우면 찾은 곳을 지웁니다. 줄바꿈(`vbLf`)을 넣으면 문서에도 줄바꿈으로 들어갑니다. 찾은 곳이 **시작하는 자리의 서식**(굵게·글자 크기)을 따릅니다. |
| 저장할 파일 <small>`OutputPath`</small> | 입력 | `string` | 결과를 저장할 파일. **비우면 원본을 고칩니다.** 적으면 원본은 그대로 두고 이 파일로 씁니다(있으면 덮어씀, 폴더가 없으면 만듦) — 서식 파일에서 문서를 찍어 낼 때 씁니다. 카드의 `…` 버튼으로 이름을 정할 수 있습니다. |
| 대소문자 무시 <small>`IgnoreCase`</small> | 설정 | `bool` | 대소문자를 가리지 않고 찾을지 여부(기본 false). |
| 개수 <small>`Count`</small> | 출력 | `int` | 바꾼 곳의 수(출력). 못 찾으면 0 이고 오류는 아닙니다 — 경고 로그가 남습니다. |
| 오류 무시 <small>`ContinueOnError`</small> | 입력 | `bool` | 이 액티비티에서 오류가 발생해도 워크플로를 멈추지 않고 계속 진행할지 여부(true/false). |

#### 서식 문서로 문서 찍어 내기 { #word-template }

1. Word 로 서식 문서를 만들고 바뀔 자리에 눈에 띄는 표시를 적어 둡니다 — 예: `{{고객명}}`, `{{금액}}`.
2. 첫 **Word 텍스트 바꾸기**: **Word 파일**에 서식 문서, **저장할 파일**에 결과 문서(`out\견적서.docx`)를 적습니다. 서식 문서는 그대로 남습니다.
3. 나머지 자리는 **Word 파일**에 그 결과 문서를 적고 **저장할 파일**은 비워 이어서 바꿉니다.

- 문서가 Word 에서 **열려 있으면 저장하지 못합니다**(읽기는 됩니다). 닫고 실행하세요.
- 자리 표시가 문서에 없으면 **개수**가 0 입니다. 표시의 철자와 대소문자를 확인하세요.
