# Text (문자열 · 정규식 · 날짜)

식을 쓰지 않고 텍스트를 다룹니다. 정규식으로 찾기·확인·바꾸기, 글자 그대로 바꾸기, 나누기·합치기·다듬기·자르기·서식 채우기, 텍스트와 날짜 사이의 변환을 제공합니다. UiPath 의 Matches·Is Match·Replace 와 텍스트·날짜 액티비티에 해당합니다.

> 이 카테고리에는 11개의 액티비티가 있습니다. 각 액티비티의 **속성** 표는 소스에서 자동 추출되며(상속 포함), 표시명·설명은 리소스/설명 데이터에서 해석됩니다.

!!! note "제공 버전"
    Text 카테고리는 NeoRPA 2.2.4 다음 버전부터 제공됩니다. 툴박스에 **Text** 가 보이지 않으면 도움말 탭 → **버전 관리** 에서 새 버전을 확인하세요.

!!! tip "어느 것을 쓸까요"
    | 하려는 일 | 액티비티 |
    |---|---|
    | 규칙(숫자, 날짜 모양, 이메일 등)에 맞는 곳을 **모두 찾기** | `정규식 찾기` |
    | 규칙에 맞는지 **예/아니요**만 알기(입력 값 검사) | `정규식 일치 확인` |
    | 규칙에 맞는 곳을 다른 텍스트로 **바꾸기**(공백 정리, 순서 바꾸기) | `정규식 바꾸기` |
    | 정해진 글자를 **그대로** 찾아 바꾸기 | `텍스트 바꾸기` |
    | 쉼표·줄바꿈으로 **나눠서 반복** 처리하기 | `텍스트 나누기` → `반복(ForEach)` |
    | 목록을 한 줄 텍스트로 **합치기** | `텍스트 합치기` |
    | 앞뒤 공백·0 **떼기** | `텍스트 다듬기` |
    | 앞 4글자, 뒤 2글자처럼 **일부만** 가져오기 | `텍스트 자르기` |
    | 값을 끼워 넣어 **문장 만들기** | `텍스트 서식` |
    | `20261118` 같은 텍스트를 **날짜로** | `텍스트를 날짜로` |
    | 날짜를 `2026-11-18` 같은 **텍스트로** | `날짜를 텍스트로` |

### 정규식 도우미 { #regex-builder }

정규식 액티비티 세 개는 카드의 패턴 칸 옆 **`.*`** 버튼(또는 속성 창 **패턴** 칸의 **…** 버튼)으로 **정규식 도우미**를 엽니다.

1. **패턴** 칸에 정규식을 적습니다. 오른쪽 **자주 쓰는 패턴…** 에서 숫자·금액·날짜·이메일·전화번호 등을 고르면 커서 자리에 들어갑니다.
2. **예시 텍스트** 에 실제 자료의 일부를 붙여 넣습니다. 고칠 때마다 아래 표가 바로 바뀌어 일치한 곳과 그룹을 보여 줍니다. 패턴이 잘못되면 까닭이 빨간 글자로 나옵니다.
3. 필요하면 **대소문자 무시 · 여러 줄 · 한 줄** 을 켭니다. `정규식 바꾸기` 에서는 **바꿀 텍스트** 와 **바꾼 결과** 도 함께 보입니다.
4. **확인** 을 누르면 패턴과 옵션이 액티비티에 들어갑니다.

예시 텍스트는 워크플로 파일에 저장되지 않습니다(창을 다시 열 때만 기억합니다). 표의 열(`Value`·`Index`·그룹)은 `정규식 찾기` 의 **데이터 테이블** 출력과 같습니다.

!!! info "패턴을 직접 적을 때"
    카드와 속성 창의 패턴 칸은 식 입력칸이라 **큰따옴표로 감싸** 적습니다(예: `"\d+"`). 정규식 도우미에서는 따옴표 없이 패턴만 적으면 됩니다. 패턴 안의 `\` 는 그대로 한 번만 씁니다.

### 결과를 쓰는 법 { #regex-results }

`정규식 찾기` 는 같은 결과를 네 가지 모양으로 돌려줍니다. 필요한 것만 변수에 연결하세요.

| 출력 | 변수 타입 | 쓰는 법 |
|---|---|---|
| 첫 일치 | String | 맨 처음 일치한 텍스트 하나만 필요할 때. 없으면 빈 문자열 |
| 개수 | Int32 | 몇 군데 일치했는지 |
| 데이터 테이블 | DataTable | 일치 항목마다 한 행. `데이터 테이블 행 반복` 으로 돌며 `row("Value")`, `row("Group1")` 을 읽습니다 |
| 결과 | IEnumerable(Of Match) | 식으로 다룰 때. `결과(0).Value`, `결과(0).Groups(1).Value` |

괄호로 묶은 부분(그룹)은 데이터 테이블에서 `Group1`, `Group2` … 열이 됩니다. `(?<이름>…)` 처럼 이름을 붙이면 그 이름이 열 이름입니다.

### 날짜 형식 { #date-format }

날짜 형식은 아래 글자를 조합해 적습니다(대소문자를 가립니다 — `MM` 은 월, `mm` 은 분).

| 글자 | 뜻 | 예 |
|---|---|---|
| `yyyy` · `yy` | 연도 4자리 · 2자리 | 2026 · 26 |
| `MM` · `M` | 월(두 자리 · 한 자리) | 03 · 3 |
| `dd` · `d` | 일 | 08 · 8 |
| `HH` · `hh` | 시(24시간 · 12시간) | 14 · 02 |
| `mm` · `ss` | 분 · 초 | 05 · 09 |
| `ddd` · `dddd` | 요일(짧게 · 길게) | 수 · 수요일 |
| `MMM` · `MMMM` | 월 이름 | 11 · 11월(영어 문화권이면 Nov · November) |
| `tt` | 오전/오후 | 오후 |

형식에 적은 `/` 와 `:` 는 **적은 글자 그대로** 쓰입니다(`yyyy/MM/dd` → `2026/11/18`). 요일·월 이름의 언어는 **문화권** 속성으로 정합니다(`ko-KR`, `en-US`). 비우면 실행하는 PC 의 설정을 따릅니다.

## 정규식 찾기  <small>`RegexMatches`</small>

텍스트에서 정규식에 맞는 곳을 모두 찾습니다. 결과는 일치 항목 목록과 함께 첫 일치 텍스트·개수·데이터 테이블(그룹이 열)로도 돌려줍니다. 일치하는 곳이 없어도 오류가 아니라 빈 결과입니다. 패턴은 카드의 `.*` 버튼으로 여는 [정규식 도우미](#regex-builder)에서 예시 텍스트에 맞춰 보며 만들 수 있습니다. UiPath Matches 에 해당합니다.

**속성**

| 속성 | 방향 | 타입 | 설명 |
|------|------|------|------|
| 입력 <small>`Input`</small> | 입력 | `string` | 찾을 대상 텍스트. 값이 없으면(Nothing) 빈 텍스트로 봅니다. |
| 패턴 <small>`Pattern`</small> | 입력 | `string` | 정규식(.NET 문법). 예: `"\d+"`(숫자), `"([A-Z])-(\d+)"`(그룹 두 개). 값을 직접 적었는데 정규식으로 읽히지 않으면 설계 시점에 경고가 납니다. |
| 대소문자 무시 <small>`IgnoreCase`</small> | 설정 | `bool` | 대소문자를 가리지 않고 찾습니다(기본 꺼짐). |
| 여러 줄 (^ $) <small>`Multiline`</small> | 설정 | `bool` | 켜면 `^` 와 `$` 가 텍스트 전체가 아니라 줄마다 처음·끝에 맞습니다. |
| 한 줄 (.) <small>`Singleline`</small> | 설정 | `bool` | 켜면 `.` 이 줄바꿈 글자에도 맞습니다. |
| 결과 <small>`Result`</small> | 출력 | `IEnumerable<Match>` | 일치 항목 목록(출력). 변수 타입은 `IEnumerable(Of Match)`. 식에서 `결과(0).Value`, `결과(0).Groups(1).Value` 로 읽습니다. |
| 첫 일치 <small>`FirstMatch`</small> | 출력 | `string` | 첫 일치 텍스트(출력). 일치하는 곳이 없으면 빈 문자열. |
| 개수 <small>`Count`</small> | 출력 | `int` | 일치한 개수(출력). |
| 데이터 테이블 <small>`DataTable`</small> | 출력 | `DataTable` | 일치 항목마다 한 행인 데이터 테이블(출력). 열은 `Value`(일치 텍스트)·`Index`(시작 위치, 0부터)와 그룹마다 하나(`Group1`…, 이름 있는 그룹은 그 이름). |
| 오류 무시 <small>`ContinueOnError`</small> | 입력 | `bool` | 이 액티비티에서 오류가 발생해도 워크플로를 멈추지 않고 계속 진행할지 여부(true/false). |

## 정규식 일치 확인  <small>`RegexIsMatch`</small>

텍스트에 정규식에 맞는 곳이 있는지 True/False 로 돌려줍니다. 입력 값이 형식에 맞는지 검사할 때 씁니다. 일부만 맞아도 True 이므로, 텍스트 전체가 맞아야 하면 패턴을 `^` 와 `$` 로 감쌉니다(예: `"^\d{3}-\d{4}-\d{4}$"`). UiPath Is Match 에 해당합니다.

**속성**

| 속성 | 방향 | 타입 | 설명 |
|------|------|------|------|
| 입력 <small>`Input`</small> | 입력 | `string` | 검사할 텍스트. 값이 없으면(Nothing) 빈 텍스트로 봅니다. |
| 패턴 <small>`Pattern`</small> | 입력 | `string` | 정규식(.NET 문법). 카드의 `.*` 버튼으로 [정규식 도우미](#regex-builder)를 엽니다. |
| 대소문자 무시 <small>`IgnoreCase`</small> | 설정 | `bool` | 대소문자를 가리지 않습니다(기본 꺼짐). |
| 여러 줄 (^ $) <small>`Multiline`</small> | 설정 | `bool` | 켜면 `^` 와 `$` 가 줄마다 처음·끝에 맞습니다. |
| 한 줄 (.) <small>`Singleline`</small> | 설정 | `bool` | 켜면 `.` 이 줄바꿈 글자에도 맞습니다. |
| 결과 <small>`Result`</small> | 출력 | `bool` | 맞는 곳이 있으면 True, 없으면 False(출력, Boolean). |
| 오류 무시 <small>`ContinueOnError`</small> | 입력 | `bool` | 이 액티비티에서 오류가 발생해도 워크플로를 멈추지 않고 계속 진행할지 여부(true/false). |

## 정규식 바꾸기  <small>`RegexReplace`</small>

정규식에 맞는 곳을 모두 다른 텍스트로 바꿉니다. 바꿀 텍스트에 `$1`, `$2`(그룹 번호)나 `${이름}` 을 적으면 찾은 내용을 끼워 넣을 수 있습니다(예: 패턴 `"(\d+)-(\d+)"`, 바꿀 텍스트 `"$2/$1"`). 바꿀 텍스트를 비우면 맞는 곳을 지웁니다. 정해진 글자를 그대로 바꾸려면 `텍스트 바꾸기` 가 더 간단합니다. UiPath Replace 에 해당합니다.

**속성**

| 속성 | 방향 | 타입 | 설명 |
|------|------|------|------|
| 입력 <small>`Input`</small> | 입력 | `string` | 바꿀 대상 텍스트. 값이 없으면(Nothing) 빈 텍스트로 봅니다. |
| 패턴 <small>`Pattern`</small> | 입력 | `string` | 찾을 정규식(.NET 문법). 카드의 `.*` 버튼으로 여는 [정규식 도우미](#regex-builder)에서 바꾼 결과까지 미리 볼 수 있습니다. |
| 바꿀 텍스트 <small>`Replacement`</small> | 입력 | `string` | 바꿀 텍스트. `$1`·`${이름}` 으로 그룹을 넣습니다. 비우면 맞는 곳을 지웁니다. `$` 글자 자체는 `$$` 로 적습니다. |
| 대소문자 무시 <small>`IgnoreCase`</small> | 설정 | `bool` | 대소문자를 가리지 않습니다(기본 꺼짐). |
| 여러 줄 (^ $) <small>`Multiline`</small> | 설정 | `bool` | 켜면 `^` 와 `$` 가 줄마다 처음·끝에 맞습니다. |
| 한 줄 (.) <small>`Singleline`</small> | 설정 | `bool` | 켜면 `.` 이 줄바꿈 글자에도 맞습니다. |
| 결과 <small>`Result`</small> | 출력 | `string` | 바꾼 텍스트(출력). 맞는 곳이 없으면 입력 그대로입니다. |
| 오류 무시 <small>`ContinueOnError`</small> | 입력 | `bool` | 이 액티비티에서 오류가 발생해도 워크플로를 멈추지 않고 계속 진행할지 여부(true/false). |

## 텍스트 바꾸기  <small>`ReplaceText`</small>

텍스트에서 찾을 텍스트를 **글자 그대로** 모두 찾아 바꿉니다. 정규식이 아니므로 `.`·`*`·`(`·`$` 같은 기호도 그 글자로 봅니다. 바꿀 텍스트를 비우면 찾은 곳을 지웁니다.

**속성**

| 속성 | 방향 | 타입 | 설명 |
|------|------|------|------|
| 입력 <small>`Input`</small> | 입력 | `string` | 바꿀 대상 텍스트. 값이 없으면(Nothing) 빈 텍스트로 봅니다. |
| 찾을 텍스트 <small>`SearchText`</small> | 입력 | `string` | 찾을 텍스트(글자 그대로). 비어 있으면 오류입니다. |
| 바꿀 텍스트 <small>`Replacement`</small> | 입력 | `string` | 바꿀 텍스트. 비우면 찾은 곳을 지웁니다. |
| 대소문자 무시 <small>`IgnoreCase`</small> | 설정 | `bool` | 대소문자를 가리지 않고 찾습니다(기본 꺼짐). |
| 결과 <small>`Result`</small> | 출력 | `string` | 바꾼 텍스트(출력). 찾을 텍스트가 없으면 입력 그대로입니다. |
| 오류 무시 <small>`ContinueOnError`</small> | 입력 | `bool` | 이 액티비티에서 오류가 발생해도 워크플로를 멈추지 않고 계속 진행할지 여부(true/false). |

## 텍스트 나누기  <small>`SplitText`</small>

텍스트를 구분 기호로 나눠 문자열 배열로 돌려줍니다. 구분 기호는 카드의 콤보에서 고르고(쉼표·줄바꿈·탭·공백·세미콜론·세로선), 다른 글자로 나누려면 **직접 입력** 을 골라 옆 칸에 적습니다. 결과는 `반복(ForEach)` 으로 하나씩 처리하거나 `결과(0)` 처럼 순번으로 읽습니다. 빈 텍스트를 나누면 항목이 0개입니다. UiPath Split Text 에 해당합니다.

**속성**

| 속성 | 방향 | 타입 | 설명 |
|------|------|------|------|
| 입력 <small>`Input`</small> | 입력 | `string` | 나눌 텍스트. |
| 구분 기호 종류 <small>`SeparatorType`</small> | 설정 | `TextSeparator` | 구분 기호 종류. 쉼표(기본) · 줄바꿈(Windows·Unix 줄바꿈 모두) · 탭 · 공백 · 세미콜론 · 세로선 · 직접 입력. |
| 직접 입력 기호 <small>`Separator`</small> | 입력 | `string` | 구분 기호 종류가 **직접 입력** 일 때의 구분 기호(예: `"//"`, `" - "`). 적은 텍스트 전체가 구분 기호 하나입니다. 직접 입력인데 비워 두면 설계 시점에 경고가 나고 실행하면 오류입니다. |
| 빈 항목 제거 <small>`RemoveEmptyEntries`</small> | 설정 | `bool` | 빈 항목을 뺍니다(`a,,b` → a, b). 항목 다듬기를 함께 켜면 공백뿐인 항목도 빠집니다. |
| 항목 다듬기 <small>`TrimEntries`</small> | 설정 | `bool` | 항목마다 앞뒤 공백을 뗍니다(`a, b` → a, b). |
| 결과 <small>`Result`</small> | 출력 | `string[]` | 나눈 항목들(출력). 변수 타입은 `String()`(문자열 배열). |
| 개수 <small>`Count`</small> | 출력 | `int` | 항목 개수(출력). |
| 오류 무시 <small>`ContinueOnError`</small> | 입력 | `bool` | 이 액티비티에서 오류가 발생해도 워크플로를 멈추지 않고 계속 진행할지 여부(true/false). |

## 텍스트 합치기  <small>`JoinText`</small>

목록(문자열 배열, List, 데이터 테이블 열 등)의 항목을 구분 기호로 이어 붙여 텍스트 하나로 만듭니다. 항목이 텍스트가 아니면 텍스트로 바꿔 붙이고, 값이 없는 항목은 빈 텍스트로 둡니다. 줄바꿈으로 합치면 Windows 줄바꿈을 넣습니다. UiPath Combine Text 에 해당합니다.

**속성**

| 속성 | 방향 | 타입 | 설명 |
|------|------|------|------|
| 값 목록 <small>`Values`</small> | 입력 | `IEnumerable` | 합칠 값 목록. 배열·List 변수, 또는 `{"a", "b", 변수}` 같은 배열 식. |
| 구분 기호 종류 <small>`SeparatorType`</small> | 설정 | `TextSeparator` | 구분 기호 종류. 쉼표(기본) · 줄바꿈 · 탭 · 공백 · 세미콜론 · 세로선 · 직접 입력. |
| 직접 입력 기호 <small>`Separator`</small> | 입력 | `string` | 구분 기호 종류가 **직접 입력** 일 때의 구분 기호(예: `", "`). |
| 결과 <small>`Result`</small> | 출력 | `string` | 합친 텍스트(출력). |
| 오류 무시 <small>`ContinueOnError`</small> | 입력 | `bool` | 이 액티비티에서 오류가 발생해도 워크플로를 멈추지 않고 계속 진행할지 여부(true/false). |

## 텍스트 다듬기  <small>`TrimText`</small>

텍스트의 앞뒤(또는 한쪽)에서 공백·탭·줄바꿈을 뗍니다. 화면이나 엑셀에서 읽은 값의 앞뒤 공백을 정리할 때 씁니다. **뗄 글자** 를 적으면 공백 대신 그 글자들을 뗍니다(예: 앞의 0 떼기).

**속성**

| 속성 | 방향 | 타입 | 설명 |
|------|------|------|------|
| 입력 <small>`Input`</small> | 입력 | `string` | 다듬을 텍스트. 값이 없으면(Nothing) 빈 텍스트로 봅니다. |
| 떼는 위치 <small>`TrimType`</small> | 설정 | `TrimMode` | 떼는 위치. 앞뒤 모두(기본) · 앞 · 뒤. |
| 뗄 글자 <small>`TrimChars`</small> | 입력 | `string` | 뗄 글자들. 적은 글자 하나하나가 대상입니다(예: `"0"` → 0 을, `"[]"` → 대괄호 두 글자를). 비우면 공백·탭·줄바꿈. |
| 결과 <small>`Result`</small> | 출력 | `string` | 다듬은 텍스트(출력). |
| 오류 무시 <small>`ContinueOnError`</small> | 입력 | `bool` | 이 액티비티에서 오류가 발생해도 워크플로를 멈추지 않고 계속 진행할지 여부(true/false). |

## 텍스트 자르기  <small>`SubstringText`</small>

텍스트의 일부를 가져옵니다. **왼쪽** 은 앞에서 길이만큼, **오른쪽** 은 뒤에서 길이만큼, **가운데** 는 시작 위치에서 길이만큼(길이를 비우면 끝까지)입니다. 텍스트보다 길게 달라고 하면 오류 대신 있는 만큼만 돌려줍니다.

**속성**

| 속성 | 방향 | 타입 | 설명 |
|------|------|------|------|
| 입력 <small>`Input`</small> | 입력 | `string` | 자를 텍스트. 값이 없으면(Nothing) 빈 텍스트로 봅니다. |
| 가져올 부분 <small>`Part`</small> | 설정 | `SubstringPart` | 가져올 부분. 왼쪽(기본) · 오른쪽 · 가운데. |
| 시작 위치 <small>`StartIndex`</small> | 입력 | `int` | 가운데일 때의 시작 위치. **첫 글자가 0** 입니다(`20261118` 에서 4 는 다섯 번째 글자 `1`). |
| 길이 <small>`Length`</small> | 입력 | `int` | 가져올 글자 수. 왼쪽·오른쪽에서는 꼭 적어야 하고, 가운데에서 비우면 끝까지 가져옵니다. |
| 결과 <small>`Result`</small> | 출력 | `string` | 잘라 낸 텍스트(출력). |
| 오류 무시 <small>`ContinueOnError`</small> | 입력 | `bool` | 이 액티비티에서 오류가 발생해도 워크플로를 멈추지 않고 계속 진행할지 여부(true/false). |

## 텍스트 서식  <small>`FormatText`</small>

서식의 자리 표시자 `{0}`, `{1}` … 를 값 목록의 값으로 채워 텍스트를 만듭니다. `{1:N0}`(천 단위 쉼표), `{0:yyyy-MM-dd}`(날짜)처럼 자리마다 표시 형식을 줄 수 있습니다. 예: 서식 `"{0} 님, 합계 {1:N0}원"`, 값 `{이름, 합계}` → `홍길동 님, 합계 1,234,567원`.

**속성**

| 속성 | 방향 | 타입 | 설명 |
|------|------|------|------|
| 서식 <small>`Template`</small> | 입력 | `string` | 서식. 자리 표시자의 번호는 0부터이고 값 목록의 순서와 맞춥니다. 중괄호 글자 자체는 `{{` 와 `}}` 로 적습니다. |
| 값 목록 <small>`Values`</small> | 입력 | `IEnumerable` | 자리에 넣을 값 목록. `{이름, 합계, Now}` 같은 배열 식이나 배열·List 변수. 자리 표시자가 값보다 많으면 오류입니다. |
| 문화권 <small>`Culture`</small> | 입력 | `string` | 숫자·날짜 표시에 쓸 문화권(예: `"ko-KR"`, `"en-US"`). 비우면 실행하는 PC 의 설정. |
| 결과 <small>`Result`</small> | 출력 | `string` | 만든 텍스트(출력). |
| 오류 무시 <small>`ContinueOnError`</small> | 입력 | `bool` | 이 액티비티에서 오류가 발생해도 워크플로를 멈추지 않고 계속 진행할지 여부(true/false). |

## 텍스트를 날짜로  <small>`ParseDate`</small>

텍스트를 날짜(DateTime)로 바꿉니다. **형식** 을 비우면 자주 쓰는 모양(`2026-11-18`, `2026.11.18`, `20261118`, `2026년 11월 18일`, 시각이 붙은 것 등)을 알아서 읽고, 형식을 적으면 그 형식에 정확히 맞아야 합니다. 읽을 수 없으면 엉뚱한 날짜로 넘어가지 않고 오류로 멈춥니다. 형식 표기는 [날짜 형식](#date-format)을 보세요.

**속성**

| 속성 | 방향 | 타입 | 설명 |
|------|------|------|------|
| 입력 <small>`Input`</small> | 입력 | `string` | 날짜가 적힌 텍스트(예: `"20261118"`). 앞뒤 공백은 무시합니다. |
| 형식 <small>`Format`</small> | 입력 | `string` | 날짜 형식(예: `"yyyyMMdd"`, `"dd/MM/yyyy HH:mm"`). 비우면 자동. 세로 막대로 여러 개를 적으면 그중 하나에 맞으면 됩니다(`"yyyyMMdd\|yyyy-MM-dd"`). |
| 문화권 <small>`Culture`</small> | 입력 | `string` | 월·요일 이름과 날짜 순서를 읽을 문화권(예: `"en-US"` 는 월/일/연). 비우면 실행하는 PC 의 설정. |
| 결과 <small>`Result`</small> | 출력 | `DateTime` | 날짜(출력). 변수 타입은 DateTime. `결과.AddDays(1)` 처럼 식에서 계산할 수 있습니다. |
| 오류 무시 <small>`ContinueOnError`</small> | 입력 | `bool` | 이 액티비티에서 오류가 발생해도 워크플로를 멈추지 않고 계속 진행할지 여부(true/false). |

## 날짜를 텍스트로  <small>`FormatDate`</small>

날짜(DateTime)를 원하는 형식의 텍스트로 바꿉니다. 파일 이름에 날짜를 넣거나 화면에 입력할 날짜 텍스트를 만들 때 씁니다. 형식을 비우면 `yyyy-MM-dd` 입니다. 형식 표기는 [날짜 형식](#date-format)을 보세요. UiPath Format Date as Text 에 해당합니다.

**속성**

| 속성 | 방향 | 타입 | 설명 |
|------|------|------|------|
| 날짜 <small>`Date`</small> | 입력 | `DateTime` | 날짜. DateTime 변수나 식(`Now` = 지금, `Today` = 오늘 0시, `Today.AddDays(-1)` = 어제). |
| 형식 <small>`Format`</small> | 입력 | `string` | 날짜 형식(예: `"yyyyMMdd"`, `"yyyy년 M월 d일 (ddd)"`, `"yyyy/MM/dd HH:mm"`). 비우면 `yyyy-MM-dd`. |
| 문화권 <small>`Culture`</small> | 입력 | `string` | 월·요일 이름에 쓸 문화권(예: `"en-US"` 면 Nov, Wed). 비우면 실행하는 PC 의 설정. |
| 결과 <small>`Result`</small> | 출력 | `string` | 날짜 텍스트(출력). |
| 오류 무시 <small>`ContinueOnError`</small> | 입력 | `bool` | 이 액티비티에서 오류가 발생해도 워크플로를 멈추지 않고 계속 진행할지 여부(true/false). |
