# AI (AI 호출)

이 PC 에 설치하고 로그인해 둔 AI 명령줄 도구(Claude Code · Codex(ChatGPT) · Gemini)를 불러 글·그림·문서를 처리하고, 결과를 워크플로 변수로 받습니다. 인증은 각 도구의 로그인을 그대로 쓰므로 API 키를 워크플로에 적지 않습니다.

> 이 카테고리에는 1개의 액티비티가 있습니다. 각 액티비티의 **속성** 표는 소스에서 자동 추출되며(상속 포함), 표시명·설명은 리소스/설명 데이터에서 해석됩니다.

!!! note "제공 버전"
    AI 카테고리는 NeoRPA 2.2.4 다음 버전부터 제공됩니다. 툴박스에 **AI** 가 보이지 않으면 도움말 탭 → **버전 관리** 에서 새 버전을 확인하세요.

!!! info "먼저 준비할 것"
    이 카테고리의 액티비티는 **워크플로를 실행하는 PC** 에 AI 명령줄 도구가 설치되어 있고 로그인되어 있어야 동작합니다. 쓰려는 도구 하나만 준비하면 됩니다.

    | 공급자 | 설치 (터미널) | 로그인 (터미널) |
    |---|---|---|
    | Claude Code (CLI) | `npm install -g @anthropic-ai/claude-code` | `claude` |
    | Codex (ChatGPT) CLI | `npm install -g @openai/codex` | `codex login` |
    | Gemini (CLI) | `npm install -g @google/gemini-cli` | `gemini` |

    설치·로그인 방법과 요금제는 각 도구의 공식 안내를 따릅니다. 준비가 끝났는지는 카드의 **연결** 아래 상태 줄에서 확인합니다(`AI 호출` 의 [연결 상태 줄](#ai-status) 참고).

!!! warning "보내는 내용에 주의하세요"
    지침·프롬프트·첨부 파일의 내용은 선택한 AI 서비스로 전송됩니다. 개인정보나 사내 기밀이 든 파일을 보내도 되는지는 회사의 보안 정책과 해당 서비스의 약관을 먼저 확인하세요.

## AI 호출  <small>`AiInvoke`</small>

AI 에게 **지침**(늘 지킬 규칙·출력 모양)과 **프롬프트**(이번 실행의 요청)를 보내고 답을 변수로 받습니다. 그림·PDF·엑셀·워드·글 파일을 함께 붙일 수 있습니다. 결과는 **연결한 변수의 타입대로** 바꿔 담습니다 — 데이터 테이블 변수면 표로, 문자열 변수면 글로 들어오므로 뒤의 액티비티가 바로 쓸 수 있습니다.

**속성**

| 속성 | 방향 | 타입 | 설명 |
|------|------|------|------|
| 지침 <small>`Instruction`</small> | 입력 | `string` | 늘 같은 규칙과 출력 모양. 예: `"명함에서 회사명, 부서, 이름, 전화번호를 뽑아 표로 만들어 줘."` 카드의 [지침 편집] 창에서는 따옴표 없이 글로 쓸 수 있습니다. 지침과 프롬프트 중 하나는 있어야 합니다. |
| 지침 자료 <small>`InstructionFiles`</small> | 입력 | `IEnumerable<string>` | 지침과 함께 보낼 참고 파일(양식 예시·규칙 문서 등)의 경로 목록. 예: `{"C:\자료\약칭표.txt"}`. 카드의 지침 옆 [첨부] 로 고릅니다. |
| 프롬프트 <small>`Prompt`</small> | 입력 | `string` | 이번 실행의 요청. 비우면 지침대로 처리합니다. 변수를 섞어 실행마다 다른 요청을 보낼 때 씁니다. |
| 프롬프트 첨부 <small>`PromptFiles`</small> | 입력 | `IEnumerable<string>` | 처리할 대상 파일(그림·PDF·엑셀 등)의 경로 목록. 예: `{"C:\스캔\명함1.png", 파일경로변수}`. 카드의 프롬프트 옆 [첨부] 로 고릅니다. |
| 공급자 <small>`Provider`</small> | 설정 | `AiProvider` | 호출할 AI 도구. Claude Code (CLI) · Codex (ChatGPT) CLI · Gemini (CLI) 중에서 카드의 **연결** 콤보로 고릅니다. 기본은 Claude Code. |
| 모델 <small>`Model`</small> | 입력 | `string` | 모델 이름. 비우면 그 도구에서 마지막에 고른 모델(CLI 설정)을 씁니다. 특정 모델로 고정하고 싶을 때만 적습니다(예: `"sonnet"`). 실제로 쓴 모델은 실행 로그에 남습니다. |
| 추론 강도 <small>`ReasoningEffort`</small> | 입력 | `string` | 추론 강도(`"low"` · `"medium"` · `"high"` 등 그 도구가 받는 값). 비우면 CLI 설정을 따릅니다. Gemini 에는 이 옵션이 없어 무시하고 로그로 알립니다. |
| 시간 제한(초) <small>`TimeoutSeconds`</small> | 입력 | `int` | 응답을 기다릴 최대 시간(초). 기본 180. 0 이거나 비우면 180 초입니다. 시간이 지나면 호출을 끝내고 오류로 처리합니다. |
| 결과 <small>`Result`</small> | 출력 | `변수의 타입` | AI 의 답(출력). 타입이 정해져 있지 않아 **연결한 변수의 타입을 따릅니다**. 변환 규칙은 아래 [결과 타입](#ai-result-type) 표를 보세요. |
| 원본 응답 <small>`RawResponse`</small> | 출력 | `string` | 변환하기 전의 응답 글 그대로(출력). AI 가 실제로 무엇을 답했는지 확인하거나, 결과와 별개로 원문을 로그·파일에 남길 때 씁니다. |
| 오류 무시 <small>`ContinueOnError`</small> | 입력 | `bool` | 이 액티비티에서 오류가 발생해도 워크플로를 멈추지 않고 계속 진행할지 여부(true/false). |

### 쓰는 순서 { #ai-usage }

1. 툴박스 **AI › AI 호출** 을 캔버스에 놓습니다.
2. **연결** 콤보에서 쓸 도구를 고르고, 바로 아래 상태 줄에 초록 점과 "로그인됨" 이 보이는지 확인합니다.
3. [지침 편집] 을 눌러 규칙과 출력 모양을 적습니다. 실행마다 달라지는 요청이 있으면 [프롬프트 편집] 에 적습니다.
4. 파일을 처리하려면 [첨부] 를 눌러 [파일 추가…] 로 고릅니다. 경로를 변수로 받으려면 식에 변수 이름을 직접 적습니다.
5. 받을 타입의 변수를 만들고(예: 데이터 테이블) **결과** 칸에 변수 이름을 적습니다. 칸 옆 배지에 그 타입이 표시됩니다.
6. 실행합니다. 어느 모델·추론 강도로 답했는지는 출력 패널의 로그에 한 줄로 남습니다.

!!! tip "지침과 프롬프트를 나누는 기준"
    반복해서 쓰는 규칙("이런 열을 가진 표로", "회사명은 약칭표대로")은 **지침**에, 그때그때 바뀌는 것("이 파일을 처리해 줘", 변수에 든 문장)은 **프롬프트**에 둡니다. 프롬프트를 비우면 지침만으로 실행합니다.

### 편집 창 { #ai-editor }

- [지침 편집]·[프롬프트 편집] 창은 **글로 쓰기**와 **식으로 쓰기 (VB · 변수 사용)** 를 오갈 수 있습니다. 글로 쓰면 따옴표나 줄 바꿈 식을 신경 쓰지 않아도 됩니다. 변수나 함수를 섞으려면 식으로 씁니다(예: `"다음 문장을 요약해 줘: " + 본문`).
- 변수가 섞인 식은 글로 바꿔 보여 줄 수 없어 식 그대로 편집합니다.
- [첨부] 창은 파일 경로를 VB 배열 식(`{"경로1", "경로2"}`)으로 다룹니다. [파일 추가…] 로 고르면 식에 경로가 추가되고, 창 아래에 파일 수와 없는 파일 수가 표시됩니다.

### 결과 타입 { #ai-result-type }

결과 변수의 타입에 맞는 **출력 형식 안내가 프롬프트 끝에 자동으로 붙으므로**, "JSON 으로 답해 줘" 같은 말을 직접 쓰지 않아도 됩니다. 표라면 어떤 열이 필요한지만 지침에 적으면 됩니다.

| 결과 변수의 타입 | 담기는 값 |
|---|---|
| `DataTable` | 표. 열 이름은 AI 가 정한 항목 이름(지침에 적은 헤더), 값은 모두 문자열 |
| `String` | 답한 글 그대로 |
| `Int32` · `Double` · `Decimal` 등 숫자 | 숫자 하나 |
| `Boolean` | True / False |
| `DateTime` | 날짜·시각 하나 |
| `JObject` · `Dictionary(Of String, Object)` | 이름-값 묶음 하나 |
| `JArray` · `List(Of String)` · `String()` | 값 목록 |
| `Object` | 답의 모양에 따라 자동으로: 표 모양이면 `DataTable`, 이름-값 묶음이면 `JObject`, 목록이면 `JArray`, 그 밖에는 `String` |

답이 그 타입으로 바뀌지 않으면(예: 숫자 변수인데 문장으로 답함) 오류로 끝나고, 오류 메시지에 AI 가 답한 글의 앞부분이 함께 나옵니다. 지침에 출력 모양을 더 분명히 적거나, 결과 변수를 잠시 `String` 으로 바꿔 답을 확인하세요. **오류 무시** 를 켜 두면 워크플로는 계속 진행되고 **원본 응답** 변수에 답이 그대로 남습니다.

### 첨부할 수 있는 파일 { #ai-attachments }

| 파일 | 처리 |
|---|---|
| 그림 `png` `jpg` `jpeg` `gif` `webp` (`bmp` `tif` `tiff` 는 PNG 로 바꿔서) | AI 가 그림을 직접 봅니다 |
| `pdf` | AI 가 파일을 직접 읽습니다 |
| 엑셀 `xlsx` `xlsm`, 워드 `docx`, 파워포인트 `pptx` | 내용을 글로 꺼내 함께 보냅니다(Excel·Word 가 설치되어 있지 않아도 됩니다) |
| 글 `txt` `csv` `json` `xml` `md` `html` `log` 등 | 내용을 그대로 함께 보냅니다 |

- 파일 하나에서 꺼낸 내용이 20만 자를 넘으면 앞부분만 보내고 로그로 알립니다.
- 예전 형식의 `xls`(Excel 97-2003 통합 문서)는 읽지 못합니다. `xlsx` 로 저장해서 붙이세요.
- 없는 경로나 폴더 경로가 들어 있으면 호출하기 전에 오류로 알립니다.
- AI 도구는 붙인 파일의 **사본**을 임시 폴더에서 읽기 전용으로 받아 처리하고, 끝나면 그 폴더를 지웁니다. 원본 파일은 바뀌지 않습니다.

### 연결 상태 줄 { #ai-status }

카드의 **연결** 콤보 아래 한 줄이 선택한 도구의 준비 상태를 보여 줍니다. 줄을 클릭하면 다시 확인합니다.

| 표시 | 뜻과 조치 |
|---|---|
| 초록 점 · 로그인됨 · 모델 … (CLI 설정) | 준비 완료. 표시된 모델은 그 도구에서 마지막에 고른 모델입니다. 모델 속성을 채웠으면 "모델은 속성 값 사용" 으로 바뀝니다 |
| 회색 점 · 설치됨 | 도구는 있지만 로그인 여부를 미리 확인하지 못했습니다. 실행해 보면 알 수 있습니다 |
| 갈색 점 · 로그인 필요 · 터미널에서 … 실행 | 터미널(명령 프롬프트)에서 표시된 명령을 실행해 로그인한 뒤 줄을 클릭합니다 |
| 빨간 점 · 설치되지 않음 · … | 표시된 설치 명령을 터미널에서 실행한 뒤 줄을 클릭합니다 |

### 문제 해결 { #ai-troubleshooting }

- **터미널에서는 로그인되어 있는데 카드는 "로그인 필요" 입니다** — AI 도구는 NeoRPA 를 실행한 Windows 계정과 환경 변수를 그대로 물려받습니다. 로그인할 때와 **같은 Windows 계정**으로 NeoRPA 가 실행되고 있는지(관리자 권한 확인 창에서 다른 계정으로 승인했다면 그 계정에서 로그인해야 합니다), 도구의 설정 폴더를 환경 변수(`CLAUDE_CONFIG_DIR`, `CODEX_HOME`)로 옮겨 쓰고 있지 않은지 확인하세요. 옮겨 쓰는 경우 NeoRPA 도 같은 환경 변수로 실행해야 합니다.
- **설치했는데 "설치되지 않음" 입니다** — 도구를 기본 위치가 아닌 곳에 설치했으면 환경 변수 `NEORPA_AI_CLI_CLAUDE`(Codex 는 `NEORPA_AI_CLI_CODEX`, Gemini 는 `NEORPA_AI_CLI_GEMINI`)에 실행 파일의 전체 경로를 넣고 NeoRPA 를 다시 시작합니다.
- **"…초 안에 응답하지 않아 중단했습니다" 로 끝납니다** — 파일이 크거나 추론 강도가 높으면 3분을 넘길 수 있습니다. **시간 제한(초)** 을 늘리거나 추론 강도를 낮추고, 첨부를 줄입니다.
- **표가 아니라 문장으로 답합니다** — 결과 변수의 타입이 `String` 이나 `Object` 인지 확인하세요. 표를 받으려면 `DataTable` 변수를 연결하고 지침에 필요한 열을 적습니다.
- **실행할 때마다 답이 조금씩 다릅니다** — AI 의 답은 같은 입력에도 달라질 수 있습니다. 지침에 열 이름·표기 규칙·예시를 구체적으로 적고, 뒤 단계에서 값을 한 번 검증하세요.
