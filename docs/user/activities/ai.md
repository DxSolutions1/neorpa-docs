# AI (AI 호출)

이 PC 에 설치하고 로그인해 둔 AI 명령줄 도구(Claude Code · Codex(ChatGPT) · Gemini)를 불러 글·그림·문서를 처리하고, 결과를 워크플로 변수로 받습니다. 인증은 각 도구의 로그인을 그대로 쓰므로 API 키를 워크플로에 적지 않습니다.

> 이 카테고리에는 1개의 액티비티가 있습니다. 각 액티비티의 **속성** 표는 소스에서 자동 추출되며(상속 포함), 표시명·설명은 리소스/설명 데이터에서 해석됩니다.

!!! note "제공 버전"
    AI 카테고리는 NeoRPA 2.2.4 다음 버전부터 제공됩니다. 툴박스에 **AI** 가 보이지 않으면 도움말 탭 → **버전 관리** 에서 새 버전을 확인하세요.

!!! info "먼저 준비할 것"
    이 카테고리의 액티비티는 **워크플로를 실행하는 PC** 에 AI 명령줄 도구가 설치되어 있고 로그인되어 있어야 동작합니다. 쓰려는 도구 하나만 준비하면 됩니다.

    | 공급자 | 설치 (터미널) | 로그인 (터미널) |
    |---|---|---|
    | Claude Code (CLI) | `npm install -g @anthropic-ai/claude-code` | `claude` |
    | Codex (ChatGPT) CLI | `npm install -g @openai/codex` | `codex login` |
    | Gemini (CLI) | `npm install -g @google/gemini-cli` | `gemini` |

    설치·로그인 방법과 요금제는 각 도구의 공식 안내를 따릅니다. 준비가 끝났는지는 카드의 **연결** 아래 상태 줄에서 확인합니다(`AI 호출` 의 [연결 상태 줄](#ai-status) 참고).

    명령줄 도구를 설치하기 어려운 PC 에서는 **API 키**로 연결할 수 있습니다(`AI 호출` 의 [API 키로 연결하기](#ai-api) 참고).

!!! warning "보내는 내용에 주의하세요"
    지침·프롬프트·첨부 파일의 내용은 선택한 AI 서비스로 전송됩니다. 개인정보나 사내 기밀이 든 파일을 보내도 되는지는 회사의 보안 정책과 해당 서비스의 약관을 먼저 확인하세요.

## AI 호출  <small>`AiInvoke`</small>

AI 에게 **지침**(늘 지킬 규칙·출력 모양)과 **프롬프트**(이번 실행의 요청)를 보내고 답을 변수로 받습니다. 그림·PDF·엑셀·워드·글 파일을 함께 붙일 수 있습니다. 결과는 **연결한 변수의 타입대로** 바꿔 담습니다 — 데이터 테이블 변수면 표로, 문자열 변수면 글로 들어오므로 뒤의 액티비티가 바로 쓸 수 있습니다.

**속성**

| 속성 | 방향 | 타입 | 설명 |
|------|------|------|------|
| 지침 <small>`Instruction`</small> | 입력 | `string` | 늘 같은 규칙과 출력 모양. 예: `"명함에서 회사명, 부서, 이름, 전화번호를 뽑아 표로 만들어 줘."` **카드에는 없고 속성 창에서 적습니다.** 값 칸 옆의 `…` 버튼을 누르면 따옴표 없이 글로 쓸 수 있는 편집 창이 열리고, 거기서 [지침 템플릿](#ai-templates) 을 불러오거나 저장합니다. 지침과 프롬프트 중 하나는 있어야 합니다. |
| 지침 자료 <small>`InstructionFiles`</small> | 입력 | `IEnumerable<string>` | 지침과 함께 보낼 참고 파일(양식 예시·규칙 문서 등)의 경로 목록. 예: `{"C:\자료\약칭표.txt"}`. 속성 창 값 칸 옆의 `…` 버튼으로 여는 창에서 [파일 추가…] 로 고릅니다. |
| 프롬프트 <small>`Prompt`</small> | 입력 | `string` | 이번 실행의 요청. 비우면 지침대로 처리합니다. 변수를 섞어 실행마다 다른 요청을 보낼 때 씁니다. |
| 프롬프트 첨부 <small>`PromptFiles`</small> | 입력 | `IEnumerable<string>` | 처리할 대상 파일(그림·PDF·엑셀 등)의 경로 목록. 예: `{"C:\스캔\명함1.png", 파일경로변수}`. 카드의 프롬프트 옆 [첨부] 로 고릅니다. |
| 공급자 <small>`Provider`</small> | 설정 | `AiProvider` | AI 를 부르는 방법. 이 PC 의 명령줄 도구인 Claude Code (CLI) · Codex (ChatGPT) CLI · Gemini (CLI), 또는 API 키로 직접 부르는 Claude API · OpenAI API · Gemini API 중에서 카드의 **연결** 콤보로 고릅니다. 기본은 Claude Code. 차이는 아래 [API 키로 연결하기](#ai-api) 를 보세요. |
| 모델 <small>`Model`</small> | 입력 | `string` | 모델 이름. 카드의 **모델** 드롭다운으로 고릅니다. 첫 항목(CLI 설정 / 기본값)은 비워 두는 것으로, CLI 연결은 그 도구에서 마지막에 고른 모델을, API 연결은 기본 모델을 씁니다. 목록에 없는 이름이나 변수는 여기 속성 창에 직접 적습니다(예: `"sonnet"`). 실제로 쓴 모델은 실행 로그에 남습니다. |
| 추론 강도 <small>`ReasoningEffort`</small> | 입력 | `string` | 추론 강도. 카드의 **강도** 드롭다운으로 고릅니다(`low` · `medium` · `high` 등 그 연결이 받는 값). 비우면 CLI 설정(API 연결은 모델의 기본값)을 따릅니다. Gemini (CLI) 에는 이 옵션이 없습니다. |
| AI 권한 <small>`Permission`</small> | 설정 | `AiPermission` | AI 가 이 PC 에서 할 수 있는 일(CLI 연결). **읽기** · **읽기/쓰기** · **모든 권한** 중에서 고르며 **기본은 모든 권한**입니다. 모든 권한이면 AI 가 프롬프트대로 파일을 만들고 고치고 지우며 프로그램·명령도 실행합니다. 꼭 아래 [AI 권한](#ai-permission) 을 읽고 고르세요. |
| 작업 폴더 <small>`WorkingFolder`</small> | 입력 | `string` | AI 권한이 읽기/쓰기·모든 권한일 때 AI 가 일하는 폴더(만든 파일이 놓이는 곳). 비우면 프로젝트 폴더입니다. 상대 경로는 프로젝트 폴더 기준이고, 없는 폴더는 만듭니다. |
| API 키 <small>`ApiKey`</small> | 입력 | `string` | API 연결의 키(평문). 직접 적으면 워크플로 파일에 그대로 저장되어 경고가 표시됩니다. **API 키(보호)** 를 쓰세요. |
| API 키(보호) <small>`SecureApiKey`</small> | 입력 | `SecureString` | API 연결의 키(보호된 문자열). [자격 증명 가져오기](security.md) 로 Windows 자격 증명 관리자에서 읽은 값을 담은 변수를 연결합니다. 값이 있으면 **API 키** 보다 먼저 쓰입니다. |
| 시간 제한(초) <small>`TimeoutSeconds`</small> | 입력 | `int` | 응답을 기다릴 최대 시간(초). 기본 180. 0 이거나 비우면 180 초입니다. 시간이 지나면 호출을 끝내고 오류로 처리합니다. |
| 재시도 횟수 <small>`RetryCount`</small> | 입력 | `int` | 호출이 실패했거나 답을 결과 변수의 타입으로 바꾸지 못했을 때 **처음부터 다시 부르는 횟수**. 기본 1, 0 이면 다시 부르지 않습니다(최대 10). 자세한 동작은 아래 [답이 맞지 않거나 호출이 실패하면](#ai-retry) 을 보세요. |
| 출력 열 <small>`OutputColumns`</small> | 입력 | `string` | 표(`DataTable`)로 받을 때의 **열 이름**을 쉼표로 구분해 적습니다(예: `"회사명, 담당자, 전화번호"`). 적으면 실행마다 그 이름, 그 순서의 열로 받습니다. 비워 두면 결과 변수에 이미 들어 있는 표의 열을 따릅니다. 자세한 동작은 아래 [표의 열을 정하기](#ai-columns) 를 보세요. |
| 결과 <small>`Result`</small> | 출력 | `변수의 타입` | AI 의 답(출력). 타입이 정해져 있지 않아 **연결한 변수의 타입을 따릅니다**. 변환 규칙은 아래 [결과 타입](#ai-result-type) 표를 보세요. |
| 원본 응답 <small>`RawResponse`</small> | 출력 | `string` | 변환하기 전의 응답 글 그대로(출력). AI 가 실제로 무엇을 답했는지 확인하거나, 결과와 별개로 원문을 로그·파일에 남길 때 씁니다. |
| 오류 무시 <small>`ContinueOnError`</small> | 입력 | `bool` | 이 액티비티에서 오류가 발생해도 워크플로를 멈추지 않고 계속 진행할지 여부(true/false). |

### 쓰는 순서 { #ai-usage }

1. 툴박스 **AI › AI 호출** 을 캔버스에 놓습니다.
2. **연결** 콤보에서 쓸 도구를 고르고, 바로 아래 상태 줄에 초록 점과 "로그인됨" 이 보이는지 확인합니다. 필요하면 그 아래 **모델**·**강도** 드롭다운에서 고릅니다(그대로 두면 CLI 설정을 따릅니다).
3. 카드를 선택하고 **속성 창의 지침** 값 칸 옆 `…` 버튼을 눌러 규칙과 출력 모양을 적습니다(저장해 둔 [지침 템플릿](#ai-templates) 을 불러올 수도 있습니다). 실행마다 달라지는 요청은 카드의 [프롬프트 편집] 에 적습니다.
4. 파일을 처리하려면 카드의 [프롬프트 첨부] 를 눌러 [파일 추가…] 로 고릅니다. 경로를 변수로 받으려면 식에 변수 이름을 직접 적습니다.
5. 속성 창의 **AI 권한** 을 확인합니다. 문서를 읽어 답만 받으면 되는 일이면 **읽기** 로 낮추세요([AI 권한](#ai-permission)).
6. 받을 타입의 변수를 만들고(예: 데이터 테이블) **결과** 칸에 변수 이름을 적습니다. 칸 옆 배지에 그 타입이 표시됩니다.
7. 실행합니다. 어느 모델·추론 강도·권한으로 답했는지는 출력 패널의 로그에 한 줄로 남습니다.

!!! tip "지침과 프롬프트를 나누는 기준"
    반복해서 쓰는 규칙("이런 열을 가진 표로", "회사명은 약칭표대로")은 **지침**에, 그때그때 바뀌는 것("이 파일을 처리해 줘", 변수에 든 문장)은 **프롬프트**에 둡니다. 프롬프트를 비우면 지침만으로 실행합니다.

### 편집 창 { #ai-editor }

- 지침 편집 창(속성 창의 지침 `…` 버튼)과 [프롬프트 편집] 창은 **글로 쓰기**와 **식으로 쓰기 (VB · 변수 사용)** 를 오갈 수 있습니다. 글로 쓰면 따옴표나 줄 바꿈 식을 신경 쓰지 않아도 됩니다. 변수나 함수를 섞으려면 식으로 씁니다(예: `"다음 문장을 요약해 줘: " + 본문`).
- 변수가 섞인 식은 글로 바꿔 보여 줄 수 없어 식 그대로 편집합니다.
- [첨부] 창은 파일 경로를 VB 배열 식(`{"경로1", "경로2"}`)으로 다룹니다. [파일 추가…] 로 고르면 식에 경로가 추가되고, 창 아래에 파일 수와 없는 파일 수가 표시됩니다.

### 결과 타입 { #ai-result-type }

결과 변수의 타입에 맞는 **출력 형식 안내가 프롬프트 끝에 자동으로 붙으므로**, "JSON 으로 답해 줘" 같은 말을 직접 쓰지 않아도 됩니다. 표라면 어떤 열이 필요한지만 지침에 적으면 됩니다.

| 결과 변수의 타입 | 담기는 값 |
|---|---|
| `DataTable` | 표. 열 이름은 AI 가 정한 항목 이름(지침에 적은 헤더), 값은 모두 문자열 |
| `String` | 답한 글 그대로 |
| `Int32` · `Double` · `Decimal` 등 숫자 | 숫자 하나 |
| `Boolean` | True / False |
| `DateTime` | 날짜·시각 하나 |
| `JObject` · `Dictionary(Of String, Object)` | 이름-값 묶음 하나 |
| `JArray` · `List(Of String)` · `String()` | 값 목록 |
| `Object` | 답의 모양에 따라 자동으로: 표 모양이면 `DataTable`, 이름-값 묶음이면 `JObject`, 목록이면 `JArray`, 그 밖에는 `String` |

답이 그 타입으로 바뀌지 않으면(예: 표 변수인데 문장으로 답함) 먼저 스스로 고쳐 봅니다([답이 맞지 않거나 호출이 실패하면](#ai-retry)). 그래도 안 되면 오류로 끝나고, 오류 메시지에 AI 가 답한 글의 앞부분이 함께 나옵니다. 지침에 출력 모양을 더 분명히 적거나, 결과 변수를 잠시 `String` 으로 바꿔 답을 확인하세요. **오류 무시** 를 켜 두면 워크플로는 계속 진행되고 **원본 응답** 변수에 답이 그대로 남습니다.

### 표의 열을 정하기 { #ai-columns }

표(`DataTable`)로 받을 때 열 이름을 정해 두지 않으면 AI 가 이름을 정합니다. 그러면 실행마다 "전화번호", "전화" 처럼 표기가 달라질 수 있고, 열 이름으로 값을 읽는 뒤 액티비티가 실패합니다. 열은 아래 순서로 정해집니다.

| 순서 | 열을 정하는 것 | 값의 타입 |
|---|---|---|
| 1 | 속성 **출력 열** 에 적은 이름(`"회사명, 담당자, 전화번호"`) | 모두 글 |
| 2 | **결과 변수에 이미 들어 있는 표**의 열. [데이터 테이블 만들기](datatable.md) 로 열을 잡아 둔 변수를 결과 칸에 넣으면 그 헤더대로 받습니다 | 그 표의 열 타입(숫자, 날짜, 참/거짓 열은 그 타입으로 바꿔 담습니다) |
| 3 | 둘 다 없으면 AI 가 정합니다 | 모두 글 |

- **지침이나 프롬프트에 적은 표 모양과 다르면 위 1, 2 가 먼저입니다.** 지침에 "열은 A, B, C 로" 라고 적혀 있어도 결과 변수의 헤더가 X, Y, Z 이면 X, Y, Z 로 받습니다.
- 결과 변수의 표에 행이 들어 있어도 열을 따릅니다. 내용은 새 결과로 바뀝니다(앞의 행에 덧붙이지 않습니다). 그래서 반복문에서 같은 변수로 다시 받으면 매번 같은 열로 받습니다.
- 정해 둔 열이 답에 없으면 **빈 열로 채우지 않습니다.** 먼저 열 이름만 고쳐 달라고 다시 요청하고([답이 맞지 않거나 호출이 실패하면](#ai-retry)), 그래도 없으면 오류로 알립니다. 오류 메시지에 없는 열과 답에 있던 열이 함께 나옵니다.
- 정하지 않은 열이 답에 더 있으면 빼고 경고 로그로 알립니다. 대소문자나 띄어쓰기만 다른 이름("전화 번호")은 같은 열로 봅니다.
- 결과 변수의 열을 따랐을 때는 출력 패널에 "결과 변수에 들어 있는 표의 열에 맞춰 받습니다: …" 가 남습니다.

!!! warning "같은 변수를 다른 표에 다시 쓸 때"
    앞에서 표를 받은 변수를 전혀 다른 요청의 결과 칸에 다시 쓰면 앞 표의 열을 따르려다 "열이 다릅니다" 오류가 납니다. 요청마다 변수를 따로 두거나, **출력 열** 에 받을 열을 적으세요.

### 답이 맞지 않거나 호출이 실패하면 { #ai-retry }

사람이 지켜보지 않는 실행에서 한 번의 실패로 워크플로가 멈추지 않도록 두 가지를 스스로 합니다. 일어날 때마다 출력 패널에 경고로 남고, 요약 줄 끝에 "호출 2회" 처럼 부른 횟수가 붙습니다.

| 상황 | 하는 일 |
|---|---|
| 답이 결과 변수의 타입에 맞지 않음(표를 받아야 하는데 설명 글로 답함) | 그 답을 그대로 보내 **형식만** 다시 내 달라고 한 번 더 부릅니다. 지침과 첨부는 다시 보내지 않아 짧게 끝납니다 |
| 호출이 실패함(AI 서비스가 잠깐 바쁨, 시간 초과 등) 또는 형식을 고치지 못함 | **재시도 횟수** 만큼 처음부터 다시 부릅니다(기본 1번, 잠깐 기다린 뒤) |
| 로그인이 풀림 · 없는 모델 이름 · 쓸 수 없는 계정 | 다시 불러도 같으므로 바로 오류로 알립니다 |

- 형식을 고칠 때 AI 가 "이 글에는 결과가 없다"고 판단하면(사과, 되묻는 글, 오류 문구) 고치지 않고 오류로 둡니다. 실패가 빈 표로 바뀌어 지나가는 일을 막기 위해서입니다.
- 형식을 고쳐서 받았으면 **원본 응답** 에는 고쳐 받은 답이 들어가고, 처음 답은 경고 로그에 앞부분이 남습니다.
- 문자열(`String`)·`Object` 변수는 어떤 답이든 담을 수 있어 형식을 다시 요청하지 않습니다.
- 시간 초과도 다시 부르므로 가장 오래 걸리면 (재시도 횟수 + 1) × 시간 제한입니다. 다시 부르지 않게 하려면 **재시도 횟수** 를 0 으로 둡니다.

### 첨부할 수 있는 파일 { #ai-attachments }

| 파일 | 처리 |
|---|---|
| 그림 `png` `jpg` `jpeg` `gif` `webp` (`bmp` `tif` `tiff` 는 PNG 로 바꿔서) | AI 가 그림을 직접 봅니다 |
| `pdf` | AI 가 파일을 직접 읽습니다 |
| 엑셀 `xlsx` `xlsm`, 워드 `docx`, 파워포인트 `pptx` | 내용을 글로 꺼내 함께 보냅니다(Excel·Word 가 설치되어 있지 않아도 됩니다) |
| 글 `txt` `csv` `json` `xml` `md` `html` `log` 등 | 내용을 그대로 함께 보냅니다 |

- 파일 하나에서 꺼낸 내용이 20만 자를 넘으면 앞부분만 보내고 로그로 알립니다.
- 예전 형식의 `xls`(Excel 97-2003 통합 문서)는 읽지 못합니다. `xlsx` 로 저장해서 붙이세요.
- 없는 경로나 폴더 경로가 들어 있으면 호출하기 전에 오류로 알립니다.
- AI 도구는 붙인 파일의 **사본**을 받아 처리하고, 끝나면 사본을 지웁니다. AI 권한이 **읽기** 이면 원본 파일은 바뀌지 않습니다.

### AI 권한 { #ai-permission }

속성 창의 **AI 권한** 이 AI 가 이 PC 에서 할 수 있는 일을 정합니다. CLI 연결에만 해당합니다.

| AI 권한 | AI 가 할 수 있는 일 | 일하는 폴더 |
|---|---|---|
| 읽기 | 붙인 파일을 읽고 답합니다. 파일을 만들거나 고치지 못하고 프로그램도 실행하지 못합니다 | 임시 폴더(끝나면 지워짐) |
| 읽기/쓰기 | 위에 더해, **작업 폴더 안**에서 파일을 만들고 고칩니다. 프로그램·명령은 실행하지 않습니다 | 작업 폴더 |
| 모든 권한 (기본) | 위에 더해, 파일을 지우고 **프로그램·명령을 실행**합니다. 터미널에서 그 도구에 직접 시키는 것과 같습니다 | 작업 폴더 |

- **작업 폴더** 는 속성 **작업 폴더** 에 적은 폴더이고, 비우면 프로젝트 폴더입니다. "결과를 보고서.xlsx 로 저장해 줘" 같은 요청으로 만든 파일이 여기 놓입니다.
- 실행 로그의 요약 줄에 "읽기/쓰기"·"모든 권한" 이 함께 남습니다.
- 답의 형식만 고쳐 달라고 다시 부를 때는 권한과 상관없이 읽기로 부릅니다.
- API 연결에는 파일·프로그램을 다루는 도구가 없어 이 속성이 적용되지 않습니다.

!!! danger "모든 권한은 사람이 지켜보지 않는 PC 에서 특히 조심하세요"
    모든 권한이면 AI 가 판단해서 파일을 지우거나 프로그램을 실행할 수 있고, **중간에 확인을 묻지 않습니다.** 붙인 문서(메일 본문, 받은 PDF, 웹에서 내려받은 파일)에 "이 명령을 실행하라" 같은 문장이 들어 있으면 AI 가 그것을 지시로 받아들일 위험도 있습니다. NeoRPA 가 그런 문장을 따르지 말라고 함께 알려 주지만 완전히 막지는 못합니다.

    - 문서를 읽어 답만 받는 일(분류, 추출, 요약)은 **읽기** 로 낮추세요.
    - 파일을 만들기만 하면 되는 일은 **읽기/쓰기** 로 충분합니다.
    - 모든 권한은 믿을 수 있는 입력만 다루는 워크플로에, 필요한 범위의 지침과 함께 쓰세요.
    - **재시도 횟수** 가 1 이상이면 실패한 작업을 처음부터 다시 합니다. 같은 일을 두 번 하면 안 되는 작업(메일 보내기 등)은 0 으로 두세요.

### API 키로 연결하기 { #ai-api }

**연결** 에서 Claude API · OpenAI API · Gemini API 를 고르면 명령줄 도구 없이 API 키로 AI 를 부릅니다. 도구를 설치·로그인하기 어려운 실행 전용 PC 에 맞습니다.

| | CLI 연결 | API 연결 |
|---|---|---|
| 준비 | 도구 설치 + 로그인 | API 키 |
| 요금 | 그 도구의 구독·요금제 | API 사용량만큼 |
| 파일 만들기·프로그램 실행 | AI 권한에 따라 가능 | 할 수 없음(묻고 답만 받음) |
| 첨부 | 그림 · PDF · 글 · 엑셀 · 워드 · 파워포인트 | 같음. 그림·PDF 는 합쳐서 18MB 까지 |
| 모델을 비우면 | 도구에서 마지막에 고른 모델 | 기본 모델 |

1. 키는 워크플로에 직접 적지 말고 Windows 자격 증명 관리자에 저장합니다([자격 증명 설정](security.md)).
2. 워크플로 앞에서 **자격 증명 가져오기** 로 그 키를 읽어 보호된 문자열 변수에 담습니다.
3. AI 호출의 속성 **API 키(보호)** 에 그 변수를 연결합니다. 카드 상태 줄이 "API 키 연결됨" 으로 바뀝니다.

- 키를 연결하지 않으면 설계할 때 경고가 표시되고, 실행하면 오류로 끝납니다.
- 오류 메시지의 "HTTP 401"·"API key not valid" 는 키가 틀렸거나 그 키로 그 모델을 쓸 수 없다는 뜻입니다.
- 서비스가 잠깐 바쁘거나(429·5xx) 연결이 끊기면 **재시도 횟수** 만큼 다시 부릅니다.

### 지침 템플릿 { #ai-templates }

자주 쓰는 지침을 이름을 붙여 저장해 두고 다른 AI 호출 액티비티에서 불러 씁니다. 지침 편집 창(속성 창의 지침 값 칸 옆 `…` 버튼) 위쪽의 템플릿 줄에서 다룹니다.

| 버튼 | 하는 일 |
|---|---|
| 템플릿 목록 + [불러오기] | 고른 템플릿의 글을 지침으로 가져옵니다. 이미 적힌 지침이 있으면 바꿀지 묻습니다 |
| [템플릿으로 저장…] | 지금 적은 지침을 새 템플릿으로 저장합니다(이름을 정합니다) |
| [템플릿 관리…] | 저장된 템플릿의 이름·내용을 고치거나 삭제하고, 새로 만듭니다 |

- 불러오면 글이 그 액티비티로 **복사**됩니다. 템플릿을 나중에 고쳐도 이미 만든 액티비티의 지침은 바뀌지 않고, 워크플로를 다른 PC 로 옮겨도 그대로 실행됩니다.
- 템플릿은 이 PC 의 데이터 폴더 `ai-templates` 에 템플릿마다 글 파일(`이름.md`) 하나로 저장됩니다. 다른 PC 에서도 쓰려면 그 폴더를 복사합니다.
- 템플릿은 글로 저장합니다. 변수가 섞인 식은 템플릿으로 저장할 수 없습니다.

### 연결 상태 줄 { #ai-status }

카드의 **연결** 콤보 아래 한 줄이 선택한 도구의 준비 상태를 보여 줍니다. 줄을 클릭하면 다시 확인합니다.

| 표시 | 뜻과 조치 |
|---|---|
| 초록 점 · 로그인됨 | 준비 완료. 그 도구가 지금 쓰는 모델은 아래 **모델** 드롭다운의 첫 항목 "CLI 설정 (…)" 에 표시됩니다 |
| 초록 점 · API 키 연결됨 | API 연결이고 키가 연결되어 있습니다(키가 맞는지는 실행해 봐야 압니다) |
| 갈색 점 · API 키 필요 | API 연결인데 키가 없습니다. 속성 창의 **API 키(보호)** 에 연결하세요 |
| 회색 점 · 설치됨 | 도구는 있지만 로그인 여부를 미리 확인하지 못했습니다. 실행해 보면 알 수 있습니다 |
| 갈색 점 · 로그인 필요 · 터미널에서 … 실행 | 터미널(명령 프롬프트)에서 표시된 명령을 실행해 로그인한 뒤 줄을 클릭합니다 |
| 빨간 점 · 설치되지 않음 · … | 표시된 설치 명령을 터미널에서 실행한 뒤 줄을 클릭합니다 |

### 문제 해결 { #ai-troubleshooting }

- **터미널에서는 로그인되어 있는데 카드는 "로그인 필요" 입니다** — AI 도구는 NeoRPA 를 실행한 Windows 계정과 환경 변수를 그대로 물려받습니다. 로그인할 때와 **같은 Windows 계정**으로 NeoRPA 가 실행되고 있는지(관리자 권한 확인 창에서 다른 계정으로 승인했다면 그 계정에서 로그인해야 합니다), 도구의 설정 폴더를 환경 변수(`CLAUDE_CONFIG_DIR`, `CODEX_HOME`)로 옮겨 쓰고 있지 않은지 확인하세요. 옮겨 쓰는 경우 NeoRPA 도 같은 환경 변수로 실행해야 합니다.
- **설치했는데 "설치되지 않음" 입니다** — 도구를 기본 위치가 아닌 곳에 설치했으면 환경 변수 `NEORPA_AI_CLI_CLAUDE`(Codex 는 `NEORPA_AI_CLI_CODEX`, Gemini 는 `NEORPA_AI_CLI_GEMINI`)에 실행 파일의 전체 경로를 넣고 NeoRPA 를 다시 시작합니다.
- **"…초 안에 응답하지 않아 중단했습니다" 로 끝납니다** — 파일이 크거나 추론 강도가 높으면 3분을 넘길 수 있습니다. **시간 제한(초)** 을 늘리거나 추론 강도를 낮추고, 첨부를 줄입니다.
- **출력 패널에 "AI 호출을 다시 시도합니다" 경고가 보입니다** — 호출이 한 번 실패해 다시 부른 것입니다. 결과가 정상이면 조치할 것은 없습니다. 자주 보이면 경고에 적힌 사유를 보고, 시간 초과면 **시간 제한(초)** 을 늘리고 형식이 맞지 않는 것이면 지침의 출력 모양을 더 분명히 적습니다.
- **표가 아니라 문장으로 답합니다** — 결과 변수의 타입이 `String` 이나 `Object` 인지 확인하세요. 표를 받으려면 `DataTable` 변수를 연결하고 지침에 필요한 열을 적습니다.
- **실행할 때마다 답이 조금씩 다릅니다** — AI 의 답은 같은 입력에도 달라질 수 있습니다. 지침에 열 이름·표기 규칙·예시를 구체적으로 적고, 뒤 단계에서 값을 한 번 검증하세요.
