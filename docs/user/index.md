- [기본 개념](concepts.md) — 프로젝트·워크플로, 셀렉터와 스코프, 실행/디버그, 로그 수준

## NeoRPA는 무엇을 하나요

화면의 버튼·입력창 같은 UI 요소를 **셀렉터**로 지정해 클릭·입력하고, Excel·파일·DB·메일을 다루며, 이 동작들을 순서·조건·반복으로 엮어 **워크플로**로 만듭니다. 워크플로는 `.xaml` 파일로 저장되고 NeoRPA에서 실행·디버그합니다.
