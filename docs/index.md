# NeoRPA 문서

**NeoRPA**는 주식회사 디엑스솔루션즈의 Windows 데스크톱 RPA 저작 도구입니다. 재호스팅된 Windows Workflow Foundation(WF) 디자이너 위에서 드래그&드롭으로 자동화 워크플로를 만들고, 브라우저·데스크톱 UI·Excel·파일·DB·메일·원격 데스크톱을 자동화합니다.

이 문서는 두 대상으로 나뉩니다.

<div class="grid cards" markdown>

-   :material-account: **사용자 가이드**

    ---

    설치부터 첫 워크플로, 액티비티 사용법, 원격 데스크톱 자동화까지. RPA를 만드는 사람을 위한 안내.

    [:octicons-arrow-right-24: 사용자 가이드 시작](user/index.md)

-   :material-shield-lock: **개발자 문서 (RPA 관리자 전용)**

    ---

    아키텍처, 설계 결정(ADR), 새 액티비티 개발, 셀렉터·브라우저·원격 런타임 내부 구조. **RPA 관리자 계정으로 로그인**해야 열람할 수 있습니다.

    [:octicons-arrow-right-24: 개발자 문서 포털(관리자 로그인)](https://brave-meadow-063b2e800.5.azurestaticapps.net/authenticated/docs/)

</div>
