# 변경 이력

NeoRPA 제품과 이 문서의 주요 변경을 최신순으로 정리합니다. 각 항목의 "원본" 표기는 문서가 반영한 NeoRPA 소스 저장소의 커밋 범위입니다.

## 2026-10-08 · NeoRPA 2.2.3 { #v2-2-3 }

!!! info "업데이트 안내"
    - **권장 업데이트**입니다. 워크플로·설정 형식 변경이 없어 언제든 이전 버전으로 되돌릴 수 있습니다.
    - 2.2.2 에서 올라갈 때 로그·자동 백업·자동화용 브라우저 프로필이 보존됩니다.
    - 설치 파일 약 143 MB. 설치 중 NeoRPA 가 종료됩니다.

### 수정

- MSI 로 설치한 PC 에서 개발용(압축 해제)으로 불러온 Chrome·Edge 확장이 NeoRPA 와 연결되지 않던 문제. 설치 프로그램이 등록하는 브라우저 연결 설정이 웹 스토어 확장과 개발용 확장을 모두 허용합니다.

## 2026-10-08 · NeoRPA 2.2.2 { #v2-2-2 }

!!! info "업데이트 안내"
    - **권장 업데이트**입니다. 2.2.1 을 설치한 뒤 시작하자마자 오류로 꺼지는 PC 는 이 버전을 설치하면 해결됩니다(앱이 켜지지 않으면 설치 파일을 직접 내려받아 설치하세요).
    - 이 버전부터 업데이트(새 버전 설치) 때도 로그·자동 백업·자동화용 브라우저 프로필이 보존됩니다. 2.2.1 이하에서 이 버전으로 올라갈 때는 이전 설치 프로그램이 이들을 한 번 지웁니다.
    - 설치 파일 약 143 MB. 설치 중 NeoRPA 가 종료됩니다.

### 디자이너

- **[업데이트] 버튼이 [버전 관리]로 바뀌었습니다**: 새 버전이 있는 등 할 일이 있으면 버튼에 ● 표식만 붙고, 버전 번호는 툴팁·상태바·창에서 확인합니다.
- **버전 관리 창 정리**: 결론 한 줄, "설치된 버전 → 권장 버전", 채널·게시일·크기, 변경 사항과 호환성을 차례로 보여 줍니다.
- 도움말 탭 아이콘(사용자 매뉴얼·액티비티 도움말·정보·버전 관리)을 다른 탭과 같은 선 아이콘으로 통일했습니다.

### 수정

- 이전 버전 파일이 설치 폴더에 남아 있던 PC 에서 설치 후 시작하자마자 "MeetupActivityLibrary … 형식을 로드할 수 없습니다"(TypeLoadException) 오류로 꺼지던 문제. 이제 설치 프로그램이 NeoRPA 의 모든 구성 파일을 새 버전으로 바꿉니다.
- 업데이트 때 `C:\NeoRPA\logs` 의 로그·자동 백업·자동화용 브라우저 프로필이 지워지던 문제.
- 설치 프로그램(MSI)으로 설치된 NeoRPA 가 없는 PC 에서 이전 버전으로 되돌리기가 "installed product not found" 로 실패하던 문제.

## 2026-10-07 · NeoRPA 2.2.1 { #v2-2-1 }

!!! info "업데이트 안내"
    - **권장 업데이트**입니다. 워크플로·설정 형식 변경이 없어 언제든 이전 버전으로 되돌릴 수 있습니다.
    - 이 버전부터 되돌리기(이전 버전 설치) 때 로그와 자동 백업이 보존됩니다(2.2.1 이후 버전끼리).
    - 설치 파일 약 143 MB. 설치 중 NeoRPA 가 종료됩니다.

### 디자이너

- **업데이트 알림이 더 잘 보입니다**: 시작 화면 하단과 디자이너 상태바 오른쪽에 "새 버전 x.y.z.w 이(가) 있습니다 · 자세히" 링크가 표시됩니다. 도움말 탭 [업데이트] 버튼에는 ● 표식이 붙습니다.
- **업데이트 창에 변경 사항이 바로 보입니다**: 권장 버전의 주요 변경 내용과 호환성 주의, 게시일·파일 크기를 창 안에서 확인하고 설치 여부를 정할 수 있습니다. [이 버전 건너뛰기]를 누르면 그 버전은 더 안내하지 않습니다(더 높은 버전이 나오면 다시 안내).
- **설치 결과 안내**: 업데이트 뒤 첫 실행에서 "x.y.z.w(으)로 업데이트되었습니다"를, 설치가 끝나지 않았으면 설치 로그 위치를 알려 줍니다.
- 켜 둔 채 며칠이 지나도 24시간마다 새 버전을 다시 확인합니다.

### 수정

- 이전 버전으로 되돌릴 때 `C:\NeoRPA\logs` 의 로그와 자동 백업이 지워지던 문제(2.2.1 이후 버전을 제거할 때부터 보존).

## 2026-10-07 · NeoRPA 2.2.0 { #v2-2-0 }

!!! info "업데이트 안내"
    - **권장 업데이트**입니다. 이 버전부터 NeoRPA 가 새 버전을 스스로 안내합니다 — 설치는 사용자가 [지금 설치]를 눌러야 시작됩니다.
    - 2.1.x 에서 저장한 워크플로는 그대로 열립니다. 되돌리기(이전 버전 설치)는 "제거 후 설치"로 진행되며, 이때 `C:\NeoRPA\logs` 의 로그와 자동 백업이 지워집니다.
    - 설치 파일 약 143 MB. 설치 중 NeoRPA 가 종료됩니다(열린 워크플로는 저장할지 묻습니다).

### 디자이너

- **업데이트 안내·설치**: 도움말 탭에 [업데이트] 버튼이 생겼습니다. 시작할 때 배포 서버의 권장 버전을 확인해 새 버전이 있으면 버튼에 "새 버전 x.y.z.w"로 표시되고, 누르면 설치된 버전·권장 버전·게시일을 보여 줍니다. [지금 설치]를 누르면 설치 파일을 내려받아 검증한 뒤 NeoRPA 를 종료하고 설치가 시작됩니다. 정보 창에도 업데이트 상태가 표시됩니다.
- **환경설정 → 작업 환경**에 "시작할 때 새 버전 확인하기"와 "업데이트 채널(안정 / 선행 검증)"이 추가되었습니다.
- 품질·보안 개선(GS 인증 대비): 입력값 검증 경고, 감사 로그, 로그 보관 기간 정리, 브라우저 연결 진단 등.

- DB 액티비티 실행 시 실행기와 디자이너가 함께 종료되던 문제를 수정했습니다.

## 2026-09-15 · NeoRPA 2.1.0 { #v2-1-0 }

원본 `dd34a1d` → `0dd0a34` (2026-08-18 ~ 2026-09-08)

### 새 액티비티

- **클릭 V2** (`ClickV2`, Control) — 탐색 범위를 제한해 빠르게 찾고, **유사 일치**(`EnableFuzzyMatching`·`FuzzyThreshold`·`RequireUniqueTarget`)로 이름이 조금 다른 요소도 찾는 개선판 클릭.
- **항목 삭제(파일/디렉토리)** (`DeleteFileOrDirectory`, Control) — 파일이든 폴더든 경로 하나로 삭제.
- **로그 필드 제거** (`RemoveLogFields`, System) — `AddLogFields`로 붙인 로그 필드 중 지정한 것만 제거.
- **For Each &lt;T&gt;** (`ForEach_T`, Statements) — 항목 형식을 지정하는 반복. 표준 WF `ForEach<T>`도 도구상자 항목으로 문서에 추가.

### 변경된 액티비티

- `텍스트 가져오기`(GetText): 윈도우·브라우저 버전이 하나로 통합되어 표시명이 "텍스트 가져오기 (윈도우)"에서 **텍스트 가져오기**로 바뀌었습니다.
- `로그 메시지 출력`(PrintLogMessage): 로그 수준에 **Fatal** 추가. 디자이너에서 선택한 LogType이 Info로 덮어써지던 문제 수정.
- `단축키 실행`(Hotkey): 키 입력 방식 개선(Win+D 같은 조합이 검색 창에 문자를 입력하던 문제 수정).
- `텍스트 입력`(TypeInto), `데이터 테이블 열 추가`(AddColumnDataTable): 기본 선택 옵션 변경.
- `엑셀 셀 읽기`(ReadCell): 결과 형식을 지정하는 제네릭 액티비티로 변경(`Read Cell`).
- Excel Scope `엑셀 VBA 실행`: VBA 실행 후 Excel UI 상태 복원·응답 대기·자동 재시작 옵션 추가.
- `데이터 추출 (일반 크롬)`(ExtractDataBrowserNative): `frame` 태그 안의 표도 추출 가능.
- 셀렉터 공통: 요소가 뒤늦게 나타나는 경우의 대기 로직 개선, 이전에 잡히지 않던 일부 윈도우 앱 요소 대응.

### 디자이너

- **시작 화면**(로컬 프로젝트 열기 / 최근 항목 열기 / 새 프로젝트)과 **프로젝트 패널**(파일 트리, 새 폴더·새 워크플로우·이름 바꾸기·삭제·드래그 이동)을 문서에 추가. 하단 바는 `출력 / 프로젝트 / 액티비티 / 디버깅`.
- **명령줄 `open` 동사** 추가: 시작 화면 없이 프로젝트를 바로 엽니다 (`open --project=… [--file=…]`).
- **디버깅 패널** 개선: 한 단계씩 코드 실행(F11) 추가, 오류 발생 시 강조 위치 이동 문제 수정, 중단점 로직 개선.
- 도구상자 더블클릭 삽입 실패·첫 문서 탭 디자인 미적용 수정.

### 원격 데스크톱 자동화

- 요소 편집기의 **검증(Validate)·하이라이트·썸네일**이 원격 셀렉터(`<rdp>`)에서도 동작합니다.
- 원격 러타임이 DPI를 인식하도록 수정되어, 원격 세션 배율 125% 등에서 좌표가 어긋나던 문제가 해결되었습니다.
- 원격 러타임 안정화: 감시자 프로세스로 크래시 시 자동 복구, 실시간 로그 창, 날짜별 로그 파일, 배포 zip 자동 생성.

### 문서

- 액티비티 페이지 생성기를 이 저장소로 옮겨 재구축했습니다(`scripts/gen_activities.py`, 설명 데이터 `data/activities.yaml`). 표시명·속성 표는 NeoRPA 소스에서 자동 추출되며, 도구상자에 보이지 않는 내부 속성은 표에서 제외됩니다.
- 시작하기·기본 개념·용어집을 프로젝트/시작 화면/디버깅 패널/로그 수준 기준으로 다시 썼습니다.
