# 다운로드

NeoRPA 설치 프로그램(MSI)을 버전별로 내려받는 페이지입니다. 보통은 NeoRPA 가 새 버전을 스스로 안내하므로(도움말 탭 → **버전 관리** → **지금 설치**) 이 페이지는 **처음 설치할 때**, **앱이 켜지지 않아 직접 설치해야 할 때**, **특정 버전으로 되돌릴 때** 사용합니다.

!!! tip "지금 쓰는 버전 확인"
    NeoRPA 리본의 **도움말** 탭 → **정보**에서 설치된 버전을 볼 수 있습니다. **버전 관리**를 누르면 설치된 버전과 권장 버전을 비교해 주고, 이 페이지로 오는 **모든 버전 다운로드** 버튼이 있습니다.

## 설치 방법 { #install }

1. 위 표에서 설치 파일을 내려받아 실행합니다. 이미 NeoRPA 가 설치되어 있으면 **같은 설치 프로그램으로 업그레이드**됩니다(설정·워크플로·라이선스는 유지).
2. 설치 중 NeoRPA 가 실행 중이면 종료됩니다. 열린 워크플로는 미리 저장하세요.
3. 설치가 끝나면 **NeoRPA** 바로가기로 실행합니다. 처음 설치라면 [시작하기](user/getting-started.md)의 라이선스 코드 입력과 브라우저 확장 프로그램 설치를 이어서 진행합니다.

!!! warning "이전 버전으로 되돌리기"
    Windows Installer 는 낮은 버전으로 덮어쓰지 못합니다. 되돌리려면 **제어판 → 프로그램 제거**에서 NeoRPA 를 먼저 제거한 뒤 원하는 버전의 설치 파일을 실행하세요. 2.2.1 이후 버전끼리는 제거해도 `C:\NeoRPA` 의 로그·자동 백업·자동화용 브라우저 프로필이 보존됩니다. 새 버전에서 저장한 워크플로는 이전 버전에서 열리지 않을 수 있습니다.

## 채널과 자동 안내 { #channels }

NeoRPA 는 시작할 때(그리고 24시간마다) 배포 서버의 **권장 버전**을 확인해 새 버전이 있으면 도움말 탭의 **버전 관리** 버튼에 ● 표식과 상태바 알림으로 알려 줍니다. 설치는 사용자가 **지금 설치**를 눌러야 시작됩니다.

| 채널 | 대상 | 설정 |
|---|---|---|
| **안정 (stable)** | 모든 사용자 기본값. 검증이 끝난 버전만 안내합니다. | 환경설정 → 작업 환경 → 업데이트 채널 |
| **선행 검증 (pilot)** | 새 버전을 먼저 받아 보는 PC. 안정 채널보다 먼저 올라갑니다. | 〃 |

자동 확인을 끄려면 환경설정의 **시작할 때 새 버전 확인하기**를 해제합니다. 폐쇄망에서는 관리자가 설정 파일의 `workspace.updateBaseUrl` 로 사내 미러를 가리킬 수 있습니다.
